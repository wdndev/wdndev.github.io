1. Selection-Based Structured Reasoning: Toward Efficient Multimodal Search Agents

Abstract:Multimodal agents commonly generate free-form reasoning before each action. For small models, limited model capacity can result in lengthy reasoning that provides little useful guidance for action generation while incurring substantial inference cost. To address this challenge, we introduce Selection-based Structured Reasoning (SSR), a framework that reformulates reasoning as selection instead of open-ended generation. SSR represents recurring high-level reasoning as pre-specified, reusable natural-language candidates. At each turn, the model selects from these reasoning candidates based on their likelihoods given the current context, without requiring an auxiliary task head. Using pre-specified reasoning traces enables parallel scoring, where teacher-forced prefilling computes token likelihoods concurrently within and across candidates using a shared context KV cache. We evaluate SSR on seven multimodal search benchmarks using 2B and 4B models. Across multiple reinforcement learning objectives and supervised fine-tuning, SSR delivers significant efficiency gains without sacrificing task performance. SSR achieves an average success rate competitive with leading search agents of the same scale, while reducing per-turn reasoning latency by over 90% and total per-question model inference latency by 28-54%. 中文摘要

摘要：多模态代理通常在每次动作之前生成自由形式的推理。对于小模型来说，有限的模型容量可能导致冗长的推理，这些推理对动作生成提供的有用指导很少，同时会带来大量推理开销。为了解决这一挑战，我们引入了基于选择的结构化推理（SSR）框架，该框架将推理重新定义为选择而非开放式生成。SSR将重复出现的高层次推理表示为预先指定的、可重用的自然语言候选项。在每一轮中，模型根据当前上下文选择这些推理候选项，而无需辅助任务头。使用预先指定的推理路径能够实现并行评分，其中教师强制填充并发计算在共享上下文KV缓存中候选项内和候选项之间的token概率。我们在七个多模态搜索基准上，使用2B和4B模型评估SSR。在多个强化学习目标和监督微调下，SSR在不牺牲任务性能的情况下实现了显著的效率提升。SSR在平均成功率方面与同规模的领先搜索代理具有竞争力，同时将每轮推理延迟降低超过90%，将每题模型总推理延迟降低28%至54%。项目页面：此 https URL。

LLM Analysis

Q: 这篇论文试图解决什么问题？ 这篇论文旨在解决\*\*小规模多模态搜索代理在每一步行动前进行自由形式推理时面临的效率与效能失衡问题\*\*。具体而言，论文针对以下核心挑战： - \*\*自由形式推理的推理成本高昂\*\* 现有ReAct风格的代理通常通过自回归解码（autoregressive decoding）逐令牌生成推理痕迹（reasoning trace）。对于参数量较小的设备端模型，这一过程引入了显著的序列生成延迟，且推理文本往往冗长重复，对后续行动生成的实际指导价值有限。 - \*\*小模型容量受限导致推理质量低下\*\* 受限于模型容量，小型多模态语言模型（MLLM）在生成开放式自然语言推理时，容易产生缺乏信息量的冗长 deliberation，浪费了生成成本却未能有效提升行动质量。 - \*\*现有压缩方法未能消除顺序依赖瓶颈\*\* 当前高效推理研究主要通过提示工程（如Chain-of-Draft）或训练目标（如效率奖励强化学习）来缩短推理长度。这些方法虽减少了生成令牌数量，但仍保留了令牌间的自回归顺序依赖，未能从根本上改变推理的表示与计算方式。 - \*\*多模态搜索任务中高层推理的高度重复性未被利用\*\* 论文观察到，在不同搜索查询中，虽然实体、查询和观察结果各异，但采取下一步行动的高层推理逻辑（如“需识别图中实体”“需查找特定事实”）具有高度复用性。现有方法未有效利用这一结构特性来避免重复的开放式生成。 为应对上述问题，论文提出\*\*基于选择的结构化推理（Selection-based Structured Reasoning, SSR）\*\*，将推理从“开放式生成”重新形式化为“从预定义的可重用自然语言候选集中进行选择”，并通过并行推理解码（parallel reasoning decoding）消除逐令牌生成的顺序延迟，从而在保持任务成功率的同时，将每轮推理延迟降低超过90%。 Q2: 有哪些相关研究？ 根据论文第2节，相关研究可分为以下三个方向： ### 1. 多模态搜索代理（Multimodal Search Agents） 该方向关注如何训练多模态代理以交错执行感知、检索与工具调用，主要工作包括： - \*\*MMSearch-R1\*\* 与 \*\*DeepMMSearch-R1\*\*：训练模型使用文本与图像搜索工具进行检索； - \*\*Visual-ARFT\*\* 与 \*\*DeepEyes\*\*：引入图像操作（如裁剪、缩放）以增强视觉推理； - \*\*DeepEyesV2\*\*：进一步结合图像操作、代码执行与网页搜索； - \*\*SenseNova-MARS\*\*、\*\*TAPO\*\* 与 \*\*WebWatcher\*\*：研究多轮强化学习、工具感知信用分配与深度研究行为； - \*\*VSearcher\*\*：在文本、图像与网页上进行长程搜索； - \*\*ProMMSearchAgent\*\*：在静态沙箱中引入过程导向奖励，再迁移至真实搜索环境。 上述工作主要聚焦于训练数据混合、梯度路由与信用分配以提升任务性能，而本文探索的是与之正交的\*\*推理效率\*\*方向。 --- ### 2. MLLM代理的高效推理（Efficient Reasoning for MLLM Agents） 该方向致力于控制模型思考过程中的计算开销，代表性方法包括： - \*\*令牌预算与测试时计算控制\*\*：通过设定令牌预算、提前停止、压缩思维链或自适应测试时计算来减少推理量（如 Token-budget-aware reasoning、Stop overthinking 等）； - \*\*推理时间预算控制\*\*：显式建模检索、交互与答案提交之间的预算权衡（Fang et al., 2026）； - \*\*HyperEyes\*\*：将推理效率作为核心训练目标，在单轮内并发调度多个有依据的查询，并奖励避免冗余工具调用的轨迹，从而减少交互轮数； - \*\*语法约束解码\*\*：通过 Grammar-constrained decoding 及 XGrammar 等引擎降低结构化输出生成时的约束检查开销。 与上述方法不同，SSR并非缩短或压缩开放式推理文本，而是\*\*改变推理本身的表示方式\*\*，通过并行评分完整候选并直接插入选定文本来消除自回归解码开销。 --- ### 3. 可复用推理与代理技能（Reusable Reasoning and Agent Skills） 该方向探索如何将推理知识或技能抽象为可复用组件，主要工作包括： - \*\*思维模板（Thought templates）\*\*、\*\*上下文感知指导原则（Context-aware guidelines）\*\*、\*\*推理记忆库（Reasoning memories）\*\* 与 \*\*任务工作流（Task workflows）\*\*：从先验知识中提炼可复用的推理模式； - \*\*StraTA\*\*：在轨迹级别生成初始策略并在整个交互中保持固定，而非根据观察动态调整； - \*\*程序化技能方法\*\*：将可复用技能编码为固定的可执行程序（如 Voyager、SkillWeaver）。 \*\*SSR与上述工作的核心区别在于\*\*： - \*\*无需辅助模块\*\*：直接利用执行代理自身的语义理解能力，通过上下文条件似然从候选库中选择，无需额外的知识管理、检索系统或分类头； - \*\*逐轮动态适配\*\*：每轮基于更新的交互历史重新选择推理候选，允许新观察改变后续行动的指导； - \*\*自然语言引导而非控制流预设\*\*：候选提供自然语言层面的行动指导，但不规定具体的可执行控制流，从而使查询内容、工具参数与最终答案保持灵活，同一候选可在不同上下文中支持不同行动。 Q3: 论文如何解决这个问题？ 论文通过提出\*\*基于选择的结构化推理（Selection-based Structured Reasoning, SSR）\*\*框架，从表示方式与计算机制两个层面系统性解决了小规模多模态搜索代理的推理效率问题。具体解决方案包含以下核心环节： ### 1. 将推理重新形式化为选择任务 SSR摒弃了传统的开放式自由生成范式，转而将每一步的推理轨迹 z_t 视为从一个预定义的、可重用的自然语言候选库 R = r_1, dots, r_N 中进行选择。该候选库由描述高层决策逻辑的短文本构成（例如“通过图像搜索识别实体”“基于已有证据作答”），覆盖搜索代理在不同上下文中反复出现的信息需求状态。这一设计将\*\*可复用的推理模式\*\*与\*\*实例特定的执行细节\*\*解耦：候选文本提供行动原理，而后续生成过程负责产生具体的工具参数（如搜索查询、裁剪框坐标）。 ### 2. 并行推理解码（Parallel Reasoning Decoding） 为了消除自回归生成的顺序延迟，SSR利用语言模型自身作为候选分类器，通过长度归一化的对数似然为每个候选评分：

Sθ(r_i mid h_t) = (1) / (K_i^α) ∑(j=1)^(Ki) log pθ(r(i,j) mid h_t, r(i,<j))
其中 Ki 为候选 r_i 的令牌数，$α ∈

控制长度归一化（论文采用 α=1$）。基于该评分，选择策略构成一个类别分布：
qθ(ri mid h_t) = (exp(Sθ(ri mid h_t)/τ)) / (∑(k=1)^N exp(Sθ(r_k mid h_t)/τ))
模型依此分布采样推理候选 z_t sim qθ(· mid ht) 。由于所有候选文本预先完全确定，该机制支持两重并行： - **令牌级并行**：通过教师强制（teacher forcing）在单次前向传播中并行计算同一候选内所有令牌的条件概率； - **候选级并行**：所有候选共享同一历史上下文 h_t 的KV缓存，从而并发评分。 这使得推理阶段的计算关键路径从自由形式的 O(L log(H+L)) 降至 O(log(H+K(max)) + log N) ，彻底移除了生成长度 L 带来的顺序因子。 ### 3. 自然语言引导的实例化行动生成 选定推理候选 zt 后，框架将其文本直接插入对话上下文，作为自然语言指导信号。随后，模型基于增强后的上下文 pθ(· mid h_t, z_t) 自回归生成具体行动 a_t （如工具调用或最终答案）。此过程确保代理无需在任何阶段生成自由形式的推理痕迹，同时保留了模型根据当前观察灵活调整行动参数的能力。 ### 4. 端到端训练适配 SSR兼容监督微调（SFT）与强化学习（RL）目标，且无需额外的分类头或SFT热启动： - **监督微调**：联合优化推理选择的类别交叉熵与行动生成的令牌级交叉熵：

**推理延迟高**：逐令牌顺序生成长度为 L 的推理文本，计算关键路径为 O(L log(H+L)) ； - **性价比低**：小模型容量有限，生成的冗长推理往往缺乏有效信息，未能为后续行动生成提供充分指导； - **可复用性未被利用**：多模态搜索任务中，虽然查询与观察各异，但“下一步该做什么”的高层决策逻辑高度重复。 —- ### 2. 方法：基于选择的结构化推理（SSR） SSR 将推理从**开放式生成**重新形式化为**从预定义候选库中选择**，核心机制如下： - **可重用推理库**：构建包含 N 条高层自然语言推理候选的固定库 R = r_1, dots, r_N 。每条候选描述当前状态下应采取的策略（如“通过图像搜索识别实体”“基于已收集证据作答”）。 - **并行推理解码**：利用语言模型自身作为分类器，对每个候选 r_i 计算其在当前历史 h_t 下的长度归一化对数似然：

Sθ(r_i mid h_t) = (1) / (K_i) ∑(j=1)^(Ki) log pθ(r(i,j) mid h_t, r(i,<j))
通过 softmax 得到选择策略 qθ(r_i mid h_t) 并采样。由于候选文本完全预定义，所有令牌可通过 **teacher forcing** 在单次前向传播中并行处理（令牌级并行），且所有候选共享同一 KV 缓存并发评分（候选级并行）。计算深度降至 O(log(H+K(max)) + log N) ，彻底消除生成长度 L 的顺序瓶颈。 - **行动生成引导**：将选中的推理文本直接插入上下文，模型随后基于 pθ(· mid h_t, z_t) 自回归生成具体行动（工具调用或答案），实现“策略指导”与“实例执行”的解耦。 - **端到端训练**：兼容 SFT 与 RL（GRPO/GSPO/SAPO）。在 RL 中，将自由形式推理的令牌级重要性比率替换为**单个类别比率** rho_t^(reason) = qθ(zt mid h_t) / q(old)(z_t mid h_t) ，并采用分离竞争者近似降低反向传播开销，无需额外分类头或 SFT 热启动。 —- ### 3. 实验结果 论文在 **7 个多模态搜索基准**（MMSearch、HR-MMSearch、FVQA-test、InfoSeek、SimpleVQA、LiveVQA、MAT-Search）上使用 **Qwen3-VL（2B/4B）** 进行验证： - **任务性能**：4B SSR 在 GRPO 训练下平均成功率达 **61.37%**，与同规模最先进模型 TAPO+GSPO（61.25%）持平；2B SSR 达 51.26%，接近零样本 8B 模型水平。 - **效率增益**：相较于自由形式推理，SSR 的**每轮推理延迟降低超过 90%**（如从约 0.9s 降至约 0.06s），**每问题总模型推理延迟降低 28–54%**，有效推理吞吐量提升逾 30 倍。 - **基线对比**：与 Chain-of-Draft、Sketch-of-Thought、效率奖励 RL 及 Probe & Prefill 等高效推理基线相比，SSR 在取得更高成功率的同时，推理延迟与 95 分位延迟均显著更低。 - **消融分析**：完整文本评分优于仅索引评分（提升 3.9%）；无 SFT 的自回归解码无法约束推理至候选库内；推理库规模从 1 增至 6 条候选时，成功率单调提升。 —- ### 4. 主要贡献 - **推理范式的转变**：首次将小规模代理的推理从开放式生成系统性地重构为结构化选择，证明有限且可复用的推理空间足以支持竞争性任务表现。 - **并行推理解码机制**：利用预指定候选实现令牌级与候选级双重并行，无需辅助分类头，在保持模型语义理解能力的同时消除自回归推理开销。 - **性能与效率的兼顾**：在多种训练目标（SFT、GRPO、GSPO、SAPO）与模型规模（2B/4B）下，SSR 均实现了与同规模自由形式模型相当或更优的成功率，同时带来实质性的推理延迟缩减。 论文的结论是，对于小规模多模态搜索代理，组织高频高层推理为紧凑、可复用的候选空间，能够构建更高效且仍具竞争力的代理系统。 Q7: 想要进一步了解论文 以上只是了解一篇论文的几个基本FAQ。如果你还想与Kimi进一步讨论该论文，请点击 这里 为你跳转Kimi AI网页版，并启动一个与该论文相关的新会话。

2. AutoSciBench: Autonomous Benchmark Generation for Evaluating Scientific Agents

Abstract:As agents rapidly evolve, existing benchmarks can become saturated, limiting their ability to distinguish capabilities and reveal remaining failure modes. Particularly in scientific domains, constructing and updating benchmarks requires substantial time, labor, and domain expertise, making it difficult to keep evaluation aligned with advances in agent capabilities. We address this challenge by investigating whether scientific-agent benchmarks can be automatically generated and iteratively adapted as agent capabilities evolve. We introduce AutoSciBench, a framework that represents each task as a high-level concept specifying the scientific domain, data modality, and required reasoning approach, together with a low-level recipe specifying how the question, environment, and ground-truth answer are constructed and verified. Agents attempt to solve each task, producing solver trajectories and corresponding judge feedback which AutoSciBench uses to revise the recipe or concept, closing observed shortcuts and shifting tasks toward raw-data re-examination, interpretation of intermediate results, and evidence integration. Experience distilled from completed refinement trajectories further guides new concept generation, allowing lessons from earlier task refinement to inform subsequent benchmark construction. Starting from existing benchmarks, we evaluate AutoSciBench across computational biology, materials science, and clinical imaging. Generated benchmarks reduce average solver accuracy by 22.4 and 25.5 percentage points relative to the human-curated benchmarks in computational biology and materials science, respectively, while generated tasks receive higher average quality ratings across all three domains, suggesting that scientific-agent evaluation can adapt as agent capabilities advance.

中文摘要

摘要：随着智能体的快速发展，现有基准测试可能会变得饱和，从而限制它们区分能力和揭示剩余失败模式的能力。尤其在科学领域，构建和更新基准测试需要大量时间、劳动和领域专业知识，这使得保持评估与智能体能力进展的同步变得困难。我们通过研究科学智能体基准是否能够自动生成并随着智能体能力的发展进行迭代调整来应对这一挑战。我们提出了 AutoSciBench 框架，该框架将每个任务表示为一个高级概念，指定科学领域、数据模态和所需的推理方法，同时提供低级配方，说明如何构建和验证问题、环境以及真实答案。智能体尝试解决每个任务，产生解算路径和相应的评审反馈，AutoSciBench 利用这些反馈修订配方或概念，封闭观察到的捷径，并将任务转向原始数据重新审查、中间结果解释和证据整合。从完成的优化轨迹中提炼的经验进一步指导新的概念生成，使早期任务优化的经验能够为后续基准构建提供参考。从现有基准出发，我们在计算生物学、材料科学和临床影像学中评估了 AutoSciBench。生成的基准在计算生物学和材料科学中，平均解算准确率分别比人工整理的基准降低了 22.4 和 25.5 个百分点，同时生成的任务在三个领域中的平均质量评分更高，这表明科学智能体的评估能够随着智能体能力的提升而自适应调整。

\*\*安全评估的自动构建\*\*：S-Eval 基于层次化风险分类学生成并筛选用于安全评估的提示（Yuan et al., 2025）。 \*\*与本文的区别\*\*：现有自动基准生成方法主要面向传统 LLM 评估，而非科学智能体任务。科学智能体评估不仅需要生成问题，还必须同时构建科学数据与交互式环境，以测试\*\*通过交互获取信息\*\*与\*\*基于间接证据进行科学推理\*\*的能力。AutoSciBench 通过引入高层概念与底层配方的双层规划、基于求解器行为的反馈引导迭代细化，以及经验引导的新概念生成，填补了上述空白。 Q3: 论文如何解决这个问题？ 论文通过提出 \*\*AutoSciBench\*\* 框架，将科学智能体基准测试的构建与适配形式化为一个自主迭代循环。该框架的核心思想是：将任务构造分解为可独立修订的高层目标与底层实现计划，利用求解器（solver）的实际行为作为反馈信号，持续增加任务难度，并将历史优化经验迁移到后续的新任务设计中。 具体解决方法可分为以下五个层次： --- ### 1. 双层计划机制：概念（Concept）与配方（Recipe） 为了将“评估科学智能体何种能力”与“如何具体构造题目”解耦，论文引入了两层规划抽象： - \*\*概念（Concept）—— 高层评估计划\*\*：表示为一个三元组 c = (d, m, O) ，其中 d 为科学领域， m 为数据模态， O 为所需操作集合。概念仅规定任务应测试的分析能力（如“整合多模态证据推断因果调控”），而不涉及具体的数据文件或问题措辞。 - \*\*配方（Recipe）—— 底层构造计划\*\*：在概念约束下，配方规划具体的问题文本、数据来源与构建方式、答案的隐藏机制、 ground-truth 的计算与验证路径、答案格式规范，以及问题隐藏策略（避免在题干中泄露解题步骤）。 这种分离使得同一概念可通过不同配方实例化为多个任务，也为后续的定向修订提供了明确的操作对象。 --- ### 2. 基于多源先验的初始概念生成 为保证概念的科学性与覆盖面，AutoSciBench 从两类外部来源提取先验知识： - \*\*现有基准\*\*：从人工构建的科学智能体基准（如 CompBioBench、MatTools、MedCTA）中抽取种子概念。 - \*\*科学文献\*\*：检索目标领域近五年的文献，提取具体研究工作流（workflow），并进一步泛化为跨研究的分析模式（pattern）。这些模式保留了 recurring 的分析步骤与决策点，同时去除研究特异性细节。 基于上述先验，框架生成新概念的候选池，确保评估目标扎根于真实科学研究实践。 --- ### 3. 反馈引导的迭代细化（Feedback-guided Iterative Refinement） 初始实现的任务往往存在两类缺陷：一是求解器可通过捷径（如单次工具调用）直接得到答案，无需进行原始数据重检或中间结果解释；二是问题或数据设计存在歧义，导致答案不唯一。为此，框架引入了基于求解器轨迹的迭代细化： - \*\*任务实现\*\*：根据当前概念 c_t 与配方 r_t 生成具体任务实例 Q_t = (q_t, F_t, a_t) ，包括问题文本、数据文件与参考答案。 - \*\*求解与评判\*\*：对 Q_t 运行 K 次独立求解试验。评判者（judge）基于求解轨迹与最终答案，评估两项指标： - \*\*可验证性（Verifiability）\*\*：问题与数据是否支持唯一、可精确匹配的答案； - \*\*难度（Difficulty）\*\*：求解器在有效试验中的经验成功率（全部正确为“简单”，部分正确为“中等”，全部失败为“困难”）。 - \*\*配方修订\*\*：若任务可验证但过于简单，或不可验证但概念本身无误，则保留概念（ c_(t+1) = c_t ），修订配方 r_(t+1) 。修订方向包括增加隐藏数据复杂度、引入干扰项、要求对中间结果进行解释，或强制整合多源证据，以消除捷径。 - \*\*概念修订\*\*：若连续多次配方修订仍无法同时满足可验证与困难，则回溯修订概念 c_(t+1) ，调整其领域、模态或操作目标，使评估需求转向更深层的推理行为，随后重新设计配方。 该迭代过程最多进行 10 轮，逐步将任务从“可直接利用中间输出”推向“必须重访原始数据、解释测量伪影、整合跨步骤证据”。 --- ### 4. 经验引导的概念生成（Experience-guided Concept Generation） 单个概念的迭代历史蕴含了关于“何种设计导致捷径、何种修订有效提升难度”的宝贵信息。为避免在后续概念生成中重复遭遇同类失败，框架设计了经验蒸馏与复用机制： - \*\*经验卡片（Experience Card）\*\*：在每次概念细化结束后，智能体自动审阅该轨迹中的任务设计、评判反馈与求解行为，总结为包含以下字段的经验卡片：设计教训（experience summary）、有效模式（useful design patterns）、反模式（anti-patterns）、选择指导（selection guidance）与生成指导（generation guidance）。 - \*\*经验记忆（Experience Memory）\*\*：累积的经验卡片构成记忆库。在生成后续新概念时，框架将记忆库中的相关卡片与外部先验（基准概念、文献模式）共同输入，指导新概念的提出。这样，早期任务中发现的有效修订策略（如“要求从观测中识别分析方法并恢复目标量”）可跨领域、跨模态迁移，催生结构相似但科学内容全新的更具挑战性的评估目标。 --- ### 5. 面向科学智能体评估的针对性设计 区别于一般 LLM 或通用智能体基准的自动生成方法，AutoSciBench 针对科学领域的两个本质特征进行了特殊设计： - \*\*交互式信息获取\*\*：配方阶段即规划“哪些信息直接提供于题干、哪些必须通过工具与数据交互获得”，强制求解器执行规划、工具调用、观察与分析的完整循环，而非仅依赖参数化知识作答。 - \*\*基于间接证据的科学推理\*\*：通过迭代细化刻意消除“执行错误即显式反馈”的通用智能体模式，转而要求求解器面对仅提供间接证据的中间输出时，能够重新检验原始数据（raw-data re-examination）、验证中间结果（interpretation of intermediate results），并跨步骤整合证据（evidence integration）。 --- 综上，AutoSciBench 通过“概念-配方”双层规划提供了可解释、可修订的任务构造中间表示；通过求解器反馈驱动的迭代细化关闭了已知捷径并持续提升任务难度；通过经验记忆的跨任务迁移实现了评估目标的自适应演化。三者协同，使科学智能体的基准测试能够伴随被测智能体能力的提升而自主进化。 Q4: 论文做了哪些实验？ 论文在 \*\*计算生物学（computational biology）、材料科学（materials science）和临床成像（clinical imaging）\*\* 三个领域开展了系统实验，以验证 AutoSciBench 生成基准的有效性、迭代细化的作用以及经验引导概念生成的价值。实验围绕以下三个核心问题展开：(1) 自动生成的基准是否具有足够的挑战性与实用性；(2) 反馈引导的迭代细化能否系统性地提升任务质量；(3) 先前细化经验能否改善后续基准生成。 各实验的具体内容如下： --- ### 1. 基准生成设置 实验以 \*\*CompBioBench\*\*（计算生物学）、\*\*MatTools\*\*（材料科学）和 \*\*MedCTA\*\*（临床成像）作为种子基准。使用 \*\*Claude Opus 4.8\*\* 与 \*\*GPT-5.6 Sol\*\* 作为生成器，每个生成器同时充当细化阶段的求解器。每个领域通过五轮经验引导的概念生成迭代，共构造 50 个任务；每个概念最多经历 10 轮细化（含初始轮），最终从每次细化轨迹中选取难度最高的可验证任务构成输出基准。 --- ### 2. 原始基准与生成基准上的模型性能对比 实验在人工整理的原始基准与 AutoSciBench 生成的基准上，评估了涵盖 Claude 系列（Opus 5、Opus 4.8、Opus 4.7、Sonnet 5、Haiku 4.5）与 GPT 系列（GPT-6 Astra、GPT-5.6 Sol、GPT-5.6 Terra、GPT-5.6 Luna、GPT-5.5）的共 10 个求解器。 \*\*主要发现：\*\* - \*\*生成基准显著更难\*\*：在计算生物学和材料科学领域，生成基准的平均求解准确率相比人工基准分别下降 \*\*22.4\*\* 和 \*\*25.5 个百分点\*\*。例如，Claude Opus 4.8 在原始 CompBioBench 上准确率为 90.4% ，而在 AutoSciBench 生成基准上降至 50.7% ；在材料科学原始基准上多家模型准确率接近天花板（平均 95.7% ），但生成基准上平均降至 70.2% （Opus 4.8）与 77.6% （GPT-5.6 Sol）。 - \*\*难度具有跨模型迁移性\*\*：即使使用与生成器不同的求解器，生成基准仍普遍表现出更低的准确率，说明任务难度并非仅针对特定生成器-求解器对。 - \*\*基准更新对应对能力演进的需求\*\*：后续发布的更强模型（如 Opus 5、GPT-6 Astra）在生成基准上准确率显著高于生成时所用模型（分别高出 19.5pp 和 15.1pp），印证了固定基准会迅速饱和，迫切需要自适应更新机制。 --- ### 3. 基准质量评估 为评估任务质量是否因难度提升而牺牲，实验引入了两名独立评判者（Claude Opus 4.8 与 GPT-5.6 Sol），从以下三个维度对人工基准与生成基准进行 1–5 分评分： - \*\*可验证性（Verifiability）\*\*：问题是否有唯一可复现的答案； - \*\*有用性（Usefulness）\*\*：是否评估了真实研究中有科学意义的任务； - \*\*适合性（Fitness）\*\*：是否适合评估智能体（需观察、规划、工具执行、多步适应等）。 \*\*主要发现：\*\* - \*\*生成基准质量全面优于人工基准\*\*：在两个评判者、三个领域下，生成基准的平均得分均高于人工基准。GPT-5.6 Sol 生成的基准在三项指标上平均得分最高（计算生物学 4.28 、材料科学 4.06 、临床成像 4.02 ）。 - \*\*适合性显著提升\*\*：生成基准的 Fitness 得分普遍更高，说明评判者认为这些任务更能有效测试智能体的规划、工具使用与多步适应能力。 - \*\*有用性保持或提升\*\*：Opus 4.8 生成的任务在计算生物学和材料科学的有用性得分（ 4.27 和 4.17 ）高于人工基准（ 3.62 和 1.49 ），表明增加难度并未以牺牲科学意义为代价。 --- ### 4. 反馈引导迭代细化的效果 实验追踪了细化轮次（最多 9 轮修订）中任务难度的分布变化，并分析了任务科学推理需求的具体转变。 - \*\*难度逐步提升\*\*：初始生成的任务以“简单”为主；随着迭代进行，“困难”任务比例持续上升，而“简单”任务比例下降。如图 4（左）所示，多轮细化后困难任务成为主导。 - \*\*推理类型的转变\*\*：以 UMI（Unique Molecular Identifier）纠错任务为例（图 4 右），初始数据中 UMI 序列无错误，求解器可直接计数；经细化后，数据被引入模拟测序错误（altered bases），求解器必须重新检视原始数据，区分真实 UMI 与错误诱导的序列变异，并结合读段支持信息进行纠错。该修订后的任务在三次独立求解试验中均导致智能体失败。 - 摘要：随着人类与人工智能的互动变得更加会话化，能够进行自然实时对话的全双工语音语言模型的重要性日益增长。除了生成适当的响应之外，这些模型还必须实时协调轮次交替、回声回应和发言管理。强化学习（RL）提供了一种通过直接反馈交互结果来优化这些行为的方法。然而，现有的RL方法要么将时序反馈应用于令牌策略，要么优化语义内容，而时序与内容的联合改进仍未解决。我们提出了HiPLEX，一种RL框架，它将预训练的全双工文本策略分解为一个控制策略（用于决定何时输出内容）和一个条件内容策略（用于决定输出什么内容）。第一个因子在“pad”、“epad”和“con”之间选择。第二个因子仅在选择“con”时选择一个令牌。这个层次结构描述了每个帧内的条件动作，并使用模型现有的文本输出头。我们通过从生成的语音片段中导出的事件因果掩码，将时序优势传递给令牌组因子，并将LLM-judge的语义优势传递给条件内容因子。在Full-Duplex-Bench v1的三个Moshi随机种子实验中，HiPLEX在自然的用户暂停和回声机会期间减少了接管率，并在相较于GRPO缩短了中断后响应延迟，同时保持了可比较的中断响应质量评估。在Moshi和PersonaPlex上，HiPLEX比GRPO更好地匹配了汇总的人类轮次时序和回声率边际分布。
