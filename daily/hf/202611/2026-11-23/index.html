1. Clover-35B-A3B-Preview Technical Report

Abstract:We introduce Clover-35B-A3B-Preview (Clover), a mixture-of-experts diffusion language model with 35 billion total parameters and 3 billion activated parameters, supporting thinking-mode generation. Clover adapts Gated Delta Networks to block diffusion by combining recurrent memory of previously generated context with bidirectional softmax attention inside the current block. Historical memory readout competes with current-block tokens in a shared softmax, with learnable block-size calibration and a separate, zero-initialized right-context convolution branch. Clover leads the seven evaluated agent metrics, including 73.6 on SWE-bench Verified and 51.7 on Terminal-Bench 2.1. On internal agent workloads, it reaches a reported generation speed of 680 tokens/s using one NVIDIA GB300 GPU at BF16 precision and batch size one. We organize the evaluation around model quality, drafting and verification costs, and deployment under constrained memory. We also describe a decision-model variant that generates answers to related questions in one denoising pass. On an internal set of 500 groups, joint prediction raises question accuracy from 90.37% to 93.88% and all-correct group accuracy from 65.4% to 77.0%.

中文摘要

摘要：我们介绍了Clover-35B-A3B-Preview（Clover），这是一种混合专家扩散语言模型，总参数量为350亿，激活参数量为30亿，支持思考模式生成。Clover通过结合之前生成上下文的循环记忆与当前块内的双向softmax注意力，将门控增量网络（Gated Delta Networks）适配于块级扩散。历史记忆读取与当前块的token在共享softmax中竞争，并具有可学习的块大小校准以及一个独立、零初始化的右上下文卷积分支。Clover在七个评估的代理指标中表现领先，包括SWE-bench Verified得分73.6和Terminal-Bench 2.1得分51.7。在内部代理工作负载中，使用一块NVIDIA GB300 GPU在BF16精度和批量大小为1的情况下，其报告的生成速度达到680 tokens/s。我们将评估组织围绕模型质量、草稿和验证成本以及受限内存下的部署进行。我们还描述了一种决策模型变体，可以在一次去噪过程中生成相关问题的答案。在内部500组测试中，联合预测将问题准确率从90.37%提高到93.88%，将全正确组准确率从65.4%提高到77.0%。

Q: 这篇论文试图解决什么问题？ 该论文试图解决的核心问题可概括为：\*\*如何将扩散语言模型（Diffusion Language Models, DLMs）的进展转化为智能体（agentic）应用中的强性能与实用效率，特别是在保持高效并行生成能力的同时，提升开源模型在复杂工具使用与代码任务上的竞争力。\*\* 具体而言，论文识别并着力解决以下关键挑战： 1. \*\*智能体能力的短板\*\* 尽管扩散语言模型在通用文本生成、推理和代码任务上取得了显著进展，但现有的开源模型（如 LLaDA2.2 flash 和 DiffusionGemma）在要求严苛的智能体基准测试上——例如可执行环境中的 \*\*Terminal-Bench 2.1\*\* 和仓库级软件工程任务 \*\*SWE-bench Verified\*\*——仍然落后于领先的自回归基线（如 Qwen 系列）。论文指出，孤立地提升推理或代码生成能力，并不足以支撑可靠的、需要与环境反复交互的仓库级问题解决。 2. \*\*并行生成效率与实际吞吐的权衡\*\* 扩散模型天然支持块级并行去噪，但将并行的“草案预测”高效地转化为实际接受的输出 token 仍面临挑战。论文关注\*\*草案生成成本\*\*与\*\*验证开销\*\*之间的平衡，并指出传统自回归投机解码（如 DFlash 2）依赖独立训练的轻量级草案模型，可能无法覆盖目标模型支持的全部工作负载范围。 3. \*\*内存受限场景下的部署可行性\*\* 论文还探讨了在消费级硬件（如单张 16GB VRAM 的 GPU）上高效部署大规模混合专家（MoE）扩散模型的可行性，涉及量化策略、专家放置（expert placement）与混合 GPU/CPU 执行的协同优化。 4. \*\*结构化联合决策的效率与质量\*\* 作为扩展方向，论文提出“决策模型”变体，探索如何利用块扩散在\*\*单次去噪过程中联合预测多个相关问题的答案\*\*，以提升完整决策集的正确率并降低端到端延迟。 简言之，Clover-35B-A3B-Preview 的提出旨在证明：通过将门控 Delta 网络适配为块扩散架构（结合历史循环记忆与当前块的双向注意力），扩散语言模型可以在\*\*智能体代码与工具使用任务\*\*上达到领先水平，同时在\*\*推理速度\*\*和\*\*端侧部署\*\*方面具备实用性。 Q2: 有哪些相关研究？ 该论文涉及的相关研究可归纳为以下几条主线： --- ### 1. 扩散语言模型的基础 formulation - \*\*连续空间扩散\*\*：Diffusion-LM 最早将扩散过程用于可控文本生成；DiffuSeq 与 DiffuSeq-v2 发展了序列到序列的扩散框架，并搭建了离散损坏与连续表示之间的桥梁

Si = α_i S(i-1), quad Si = S_i + β_i (v_i - S_i k_i) k_i^top
其中 α_i 控制历史保留， β_i 控制新写入强度。该状态在块的去噪过程中保持固定，显著降低长上下文推理的内存占用。 - **当前块：双向注意力交互** 对于正在去噪的块内 token，模型允许双向访问。查询 j 首先计算历史 readout：
r_j = S_b q_j / √d_k
随后与块内所有 token 的键值通过**共享 softmax** 竞争：
ell(ji) = sh q_j^top k_i quad (i ∈ A_b), quad ell(j,hist) = bh + c_h log(N_b / N(ref))

(p(ji), p(j,hist)) = softmax(ell(ji), ell(j,hist))

oj = p(j,hist) rj + ∑(i ∈ A)b p(ji) vi
其中 s_h, b_h, c_h 为可学习的头级标量，分别控制局部 logit 缩放、历史偏置与块大小校准。该设计使每个查询能同时利用压缩历史与块内双向上下文，既保留了扩散的并行性，又避免了未来块的信息泄露。 - **独立双向短卷积** 在 Q/K/V 投影后引入独立的右向卷积核（零初始化），与预训练的因果卷积核相加：
a(c,i) = ∑(r=0)^(W-1) w^(arrow)(c,r) u(c,i-(W-1-r)) + ∑(m=1)^(W-1) w^(arrow)(c,m) u(c,i+m)
右向卷积严格限制在当前块内，不跨块或跨示例边界，从而在初始化时退化为因果模型，训练后逐步学习局部双向特征。 —- ### 2. 块级专家路由：dMoE 为解决并行块预测导致的专家选择碎片化问题，Clover 采用 **dMoE（decision MoE）** 进行块级协调： 1. 先对每个有效块 token 计算 routed expert 的 top-8 概率； 2. 按专家聚合块内概率质量，选取覆盖比例 τ=0.9 的最小专家子集作为**块核心集（block coreset）**； 3. 在核心集内重新执行 token 级 top-8 选择与归一化权重 p_(je) 。 模块输出为：

dMoE(fj) = g_s(f_j) E_s(f_j) + ∑(e ∈ T)j p(je) Ee(f_j)
该机制鼓励并行预测间复用专家，同时保留 token 级特异性；因果验证阶段则恢复普通 token 级路由。 —- ### 3. 训练策略：双流联合目标 Clover 采用**双流训练**，同一示例同时构造带噪声的扩散流与干净的自回归流，共享主干参数： - **块扩散目标** L(BD) ：对掩码位置进行无偏移的干净 token 预测； - **辅助因果目标** L_(AR) ：对干净流执行传统的 next-token 预测。 联合损失为：

L = λ(BD) L(BD) + λ(AR) L(AR)
训练时从 4, 8, 16, 32 中均匀采样块大小，并在序列打包后通过显式的示例/流/块身份掩码严格隔离可见性：噪声查询只能读取其所在块内的其他噪声 token 及之前的干净前缀，禁止访问其他噪声块或对应的干净目标块。 —- ### 4. 解码策略：自投机解码与置信度控制 为将并行预测高效转化为实际接受的 token，Clover 采用**自投机解码（self-speculative decoding）**： - **草案生成**：通过单步扩散并行预测整个块的 token； - **验证机制**：使用同一模型的因果 GDN 路径对草案进行顺序验证。论文采用**基于熵的宽松接受准则**：

p(d) ≥ δ exp(-H)
其中 H 为验证分布的熵， δ 为预设超参数。该准则在低熵（高确定性）时放宽接受阈值，在高熵时收紧，从而平衡速度与质量。 - **提交规则**：顺序验证直至首个拒绝，仅提交接受前缀，随后对剩余位置重新掩码并迭代。 此外，模型引入历史感知的 presence/repetition penalty 与针对停止 token、 </think> token 的长度相关正 logit 偏置，以抑制重复并控制 thinking 模式下的输出结构。 —- ### 5. 端侧部署优化：量化与专家放置 针对 16 GB 消费级 GPU，Clover 通过以下策略实现高效部署： - **INT4 量化与混合执行**：routed expert 权重使用 INT4（group size 32），主干网络保持 BF16；每层将 96 个专家置于 GPU、160 个置于 CPU，利用 AVX-512 加速 CPU 计算。 - **路由感知的专家放置**：基于数学任务的路由统计，将高频专家固定在 GPU、低频专家 offload 至 CPU。此策略在保持 97.6% MATH-500 准确率的同时，将解码吞吐量从 66.64 tokens/s 提升至 97.52 tokens/s；若进一步将验证阶段激活专家减至 top-6，吞吐量可达 106.25 tokens/s（准确率 96.0%）。 —- ### 6. 决策模型变体：联合多答案预测 为支持结构化快速决策，Clover 还探索了**单次去噪联合预测**：将共享材料与最多 8 个问题置于同一上下文，在一个扩散块中为每个问题设置独立的掩码答案位。所有答案位共享上下文并可在块内交换中间特征。实验表明，在 500 组内部多问题集上，联合预测将单问题准确率从 90.37% 提升至 93.88%，全对组准确率从 65.4% 提升至 77.0%；在 4×4 数独补全任务上，联合模式将板级全对率从 22.0% 大幅提升至 76.0%。 —- ### 总结 通过上述设计，Clover 将**循环历史记忆**、**块内双向注意力**、**块大小自适应校准**与**块级专家复用**相结合，辅以**自投机验证**与**工作负载感知的混合执行**，在保持扩散模型并行生成优势的同时，显著提升了其在仓库级代码、终端交互与工具使用等智能体任务上的能力，并支持从数据中心级 GPU 到消费级 16 GB 显卡的广泛部署场景。 Q4: 论文做了哪些实验？ 论文的实验围绕**模型质量**、**生成速度与成本**、**端侧部署**以及**联合决策**四个维度展开，具体如下： —- ### 1. 主基准性能评估（Section 3.6, Table 1） 在 **18 个基准测试** 上，将 Clover-35B-A3B-Preview 与 5 个基线模型进行对比： - 2. Lost in the Hallway: Benchmarking Persistent Spatial Memory Across Revisits

Abstract:Persistent spatial understanding is essential for embodied agents to operate reliably in environments they repeatedly encounter. It requires recognizing revisited places despite viewpoint changes, distinguishing them from similar-looking rooms, and updating memories as environments change. Yet existing evaluations often leave physical place identity across separated visits implicit. We introduce ReSpaceBench, a benchmark comprising 3,244 questions across 590 synthetic and real-home scenes, organized into 9 tasks spanning room association, persistent state tracking, and downstream reasoning. Controlled walkthroughs define visits by physical room entry and deliberately include same-type room distractors and cross-session object changes. Our evaluation of 32 models and 3 agentic video-understanding frameworks reveals substantial limitations: the strongest evaluated zero-shot model achieves 50.5% overall accuracy and 52.2% on a 450-question subset, compared with 90.1% for human annotators. The evaluated agentic frameworks offer no overall improvement over direct inference with the same base model. Analysis of agent execution traces reveals evidence omissions and incorrect cross-visit room associations as major failure modes, suggesting that iterative evidence seeking alone does not ensure consistent spatial memory. Further analyses expose a gap between recognizing familiar rooms and identifying the correct visited room, while annotation-guided sampling highlights the importance of preserving intervening visits and transitions. We also provide RS-30K, a separate training dataset from synthetic sources with no template, scene, route, or video overlap with the benchmark. Fine-tuning Qwen3-VL-8B raises overall accuracy from 35.5% to 60.4%, with the largest gains in association and improvements extending to real-life scenes.

**跨会话状态变化（cross-session state changes）** 在 T7 任务中，通过多次进入同一家庭并改变物体布局，测试模型能否在正确关联房间身份的前提下，跟踪并更新物体状态记忆。 - **多源数据与严格质控** 数据来源包括合成环境（3D-FRONT、ProcTHOR）、FARO 激光扫描的真实家居，以及 PICO 头显录制的真实第一视角视频。每条问题均通过自动化的路线验证、答案重算、可见性检查与人工复核，排除因渲染瑕疵或标注不一致导致的歧义。 —- ### 2. 提供独立训练数据集 RS-30K 为支撑模型改进并避免数据泄漏，论文同步发布了 **RS-30K**： - 3. PURE: A Diagnostic Benchmark for Multi-Granularity Multimodal Identity Matching

Abstract:Identity matching asks whether two records denote the same identity, yet the answer depends on the target granularity. Two records may match at the base level but not at the variant level: they share an underlying design while differing in attributes such as color or size. Final matching accuracy does not separately characterize the capabilities involved. To study this problem, we use e-commerce as a challenging real-world domain. We introduce PURE, a diagnostic benchmark for multi-granularity multimodal identity matching covering four capability dimensions: Perception, Understanding, Reasoning, and Evidence-grounded Judgment. The benchmark comprises 1,457 multiple-choice questions across 14 tasks, derived from real-world matching pairs and verified by two domain experts. Across ten recent MLLMs, overall scores range from 47.1% to 86.0%. Understanding receives the highest mean score and Judgment the lowest, with weaknesses in visual difference localization and variant-level rule judgment. Modality ablations show that models benefit from multimodal evidence but can incorrectly identify conflicts between matching records. In direct matching, most models recognize matching pairs more reliably than non-matching pairs at the base level, whereas the reverse holds at the variant level. PURE therefore reveals what aggregate matching accuracy hides: not only whether models judge a pair correctly, but where they struggle to interpret evidence and apply matching criteria.

4. Prune to Expand: Training Prompt Enhancers with Less to Imitate

Abstract:Prompt enhancement (PE) refines concise user prompts into detailed descriptions to improve the compositional aesthetics of generated images while preserving user intent. A common practice constructs supervised fine-tuning (SFT) pairs by deriving short, user-like prompts from dense captions, implicitly assuming that captions that improve image generation also provide effective supervision. In this paper, however, we uncover a counterintuitive finding: PE models trained on caption pairs with substantial generation gains perform comparably to those trained on pairs with only marginal gains. We argue that dense captions can impose redundant supervision by requiring PE models to reproduce image-specific details weakly related to user intent. Motivated by this discrepancy, we introduce Prune to Expand (P2E), a simple text-only method that refines dense-caption supervision by selectively removing redundant sentences under a per-example deletion bound while preserving explicit user requirements and informative visual structure. Extensive experiments under identical training configurations demonstrate that P2E improves alignment with human preferences and visual quality over conventional dense-caption SFT across diverse image categories and visual generators.

5. AeroRSI: Recursive Self-Improvement for Aerial Vision-Language Navigation

Abstract:Vision-language-action (VLA) models enable unmanned aerial vehicles (UAVs) to follow natural-language instructions, yet still fail frequently in closed-loop flight. Correcting these failures requires repairs, i.e., actions that avoid them at the states the policy itself reaches, which human pilots cannot label at scale and rule-based planners cannot supply reliably. In this paper, we present AeroRSI, a recursive self-improvement framework in which an aerial navigation policy iteratively learns from its own failures. Our key insight is that a failing policy should judge its own repairs by flying on from them. Judged in this way, its sampled actions and even rule-based proposals that hurt it when imitated directly become reliable supervision. Moreover, an episode terminates at its first failure, concealing subsequent failures until the earlier ones are repaired. AeroRSI thus renews its supervision in every round, anchoring the failures of the current policy, verifying repairs by its continuation, and distilling them while keeping its behavior elsewhere. On TravelUAV, three rounds raise the success rate of a supervised 2B-parameter policy from 46.4% to 67.5% and reduce collisions by half, surpassing the previous state of the art by 10.6 points from the same initialization without extra human labels or inference cost. 中文摘要

摘要：视觉-语言-动作（VLA）模型使无人机（UAV）能够遵循自然语言指令，但在闭环飞行中仍然经常失败。纠正这些失败需要修复，即在策略自身到达的状态下采取避免失败的动作，而人类飞行员无法大规模标注这些动作，基于规则的规划器也无法可靠提供。在本文中，我们提出了 AeroRSI，这是一种递归自我改进框架，空中导航策略在其中能够从自身的失败中迭代学习。我们的关键见解是，失败的策略应通过从修复后的状态继续飞行来评估自身的修复效果。通过这种方式评估后，策略采样的动作甚至直接模仿会导致失败的基于规则的建议都可以成为可靠的监督信号。此外，一条飞行轨迹在首次失败时即终止，从而隐藏了后续失败直至前面的失败被修复。因此，AeroRSI 在每一轮中更新监督信号，固定当前策略的失败，验证通过继续飞行的修复效果，并在保持其他行为的同时蒸馏这些修复。在 TravelUAV 数据集上，经过三轮训练，监督式 2B 参数策略的成功率从 46.4% 提升至 67.5%，碰撞次数减少一半，比在相同初始化下、无需额外人工标注或推理成本的先前最先进方法提高了 10.6 个百分点。代码和模型可在此 https URL 获取。

LLM Analysis

Q: 这篇论文试图解决什么问题？ 该论文旨在解决\*\*空中视觉-语言导航（Aerial Vision-Language Navigation, VLN）中视觉-语言-动作（VLA）模型在闭环飞行时频繁失败\*\*的问题。 具体而言，现有无人机策略在将视觉观测与自然语言指令映射为飞行动作时，常因碰撞障碍物、偏离目标或陷入死局等错误导致任务终止，严重限制了系统的可靠性。造成这一现象的核心原因是\*\*模仿学习中的分布不匹配（distribution mismatch）\*\*：训练于专家演示的策略在部署时会到达演示未覆盖的状态，并沿飞行轨迹累积误差。 要纠正这些失败，需要获取\*\*修复动作（repairs）\*\*——即在策略自身实际到达的失败状态上，能够避免失败并继续任务的动作。然而，论文指出获取此类动作级监督面临以下关键障碍： - \*\*人工标注成本极高\*\*：交互式模仿学习虽可请求专家标注修正动作，但人类飞行员无法大规模标注策略自身遇到的每一个失败状态。 - \*\*规则规划器缺乏指令理解\*\*：基于规则的规划器（如势场法）生成的修正动作往往忽略语言指令，且直接模仿这些动作反而可能损害策略性能。 - \*\*现有自动校正未考虑策略可执行性\*\*：基于碰撞回滚、参考路径或辅助教师策略的自动校正方法，未验证当前策略本身是否具备执行这些修正的能力。 - \*\*强化学习缺乏动作级信号\*\*：强化学习仅提供回合级（episode-level）奖励，只能表明飞行是否成功，无法指明在具体失败状态下应当采取哪个动作。 针对上述问题，论文提出 \*\*AERORSI\*\* 框架，其核心思想是\*\*让失败的策略通过“继续飞行”来自行验证候选修复动作\*\*。通过将策略自身的采样动作与简单的基于规则提案（如爬升、绕行）作为候选，并利用当前策略的后续飞行轨迹进行蒙特卡洛式验证，原本不可靠的候选动作被转化为策略能够执行且确实有效的监督信号。该过程通过递归执行，在每一轮针对当前策略新暴露的失败状态重新锚定、验证并蒸馏修复动作，从而迭代提升导航成功率，且无需额外人工标注或增加部署时的推理开销。 Q2: 有哪些相关研究？ 论文在第2节系统梳理了三个相关研究方向，现分述如下。 --- ### 1. 空中视觉-语言导航（Aerial Vision-Language Navigation） 该领域早期研究将地面视觉-语言导航（VLN）扩展至无人机，建立了 AerialVLN、TravelUAV、OpenFly 等基准测试。后续工作沿多个维度展开改进： - \*\*架构与表示\*\*：跨具身预训练（如 NavFoM）、长程时空上下文建模（如 LongFly）、增强对误差累积鲁棒性的记忆机制（如 NeuroKalman）、未来预测（如 ForeFly、DreamFly、WorldFly 等）以及空间推理增强。 - \*\*轻量级 VLA 策略\*\*：AerialVLA 与 AeroDPO 表明，参数量仅为 2B 的视觉-语言-动作模型即可匹敌更大规模模型。 - \*\*后训练优化\*\*：AeroDPO 通过基于碰撞回滚合成的修正进行偏好优化；RefineFly 等方法采用在线强化学习进一步微调。 与上述方法相比，AERORSI 不修改模型架构，也不依赖回合级奖励或外部合成的无验证修正，而是\*\*让策略通过自身继续飞行来验证动作级修复\*\*，可与现有架构互补结合。 --- ### 2. 从修正中学习（Learning from Corrections） 该方向关注如何为策略自身遇到的失败状态获取修正动作： - \*\*交互式模仿学习\*\*：DAgger 及其变体（HG-DAgger、DART、ThriftyDAgger）通过查询专家标注学习者遇到的状态；AggreVaTe 利用专家的成本-to-go 对动作排序。这些方法需昂贵的人工专家标注。 - \*\*基于专家或仿真数据的导航修正\*\*：早期工作从真实碰撞、脱离事件或仿真环境中学习单目反应式控制。 - \*\*自动合成修正以避免人工标注\*\*：AeroDPO 利用碰撞回滚生成修正；CorrectNav 基于参考路径生成修正；残差策略方法通过辅助网络提供修正。这些修正由启发式、参考路径或其他策略评判，\*\*未考虑当前策略自身能否执行\*\*。 - \*\*学习目标差异\*\*：现有方法采用监督学习、偏好优化（DPO/ORPO）或强化学习优化这些修正，但偏好更新可能将概率转移至非预期动作。 AERORSI 的核心差异在于：\*\*评判主体是当前策略自身而非外部专家或参考\*\*。通过继续飞行（continuation）来估计候选动作的值，并直接蒸馏验证后的最优候选，而非与失败动作做显式对比。 --- ### 3. 递归自我改进（Recursive Self-Improvement） 该方向研究模型如何从自身生成的、经验证的输出中学习迭代提升： - \*\*大语言模型中的自我改进\*\*：专家迭代（Expert Iteration）、自训练（Self-training）、STaR（通过推理自举推理）、ReST 等方法通过多轮自我训练显著提升推理能力。近期分析指出，这种提升主要强化模型已能产生的输出，而非获得全新能力。 - \*\*机器人与导航中的扩展\*\*：包括 RoboCat 等自改进通才智能体、从残差 RL 获取修正、基于代码或多模态智能体构建、利用学习模型指导数据收集、重训练自身轨迹与推理链（如 Data-centric RSI、EvolveNav）等。通用形式化框架如 Generalized Agent Iteration 亦被提出。 - \*\*最接近的相关工作\*\*： - \*\*CorrectNav\*\*：反复将策略重训练于朝向参考路径的误差修正，但依赖参考路径。 - \*\*局部恢复监督（Local Recovery Supervision）\*\*：检查冻结学生能否从教师的恢复动作中继续，但依赖教师策略。 - \*\*基于展开的策略迭代与学习搜索（Rollout-based Policy Iteration / Learning to Search）\*\*：通过后续展开评判动作，但通常限于小规模动作集或需遵循参考策略。 AERORSI 将“继续验证”引入参数量达 2B、动作空间近百万的空中 VLA 策略，通过\*\*从恢复状态进行蒙特卡洛继续\*\*来验证策略采样动作与物理先验（规则提案），无需参考路径或教师策略；同时通过\*\*保持性修复学习（RRL）\*\*保留策略在无故障状态上的原有行为，避免在蒸馏修复时发生行为漂移。 Q3: 论文如何解决这个问题？ 论文通过提出 \*\*AERORSI\*\*（Recursive Self-Improvement for Aerial navigation）框架，将闭环飞行中的失败修复问题形式化为\*\*近似策略迭代（approximate policy iteration）\*\*，并针对无人机导航的两个核心难点——\*\*动作价值的随机性\*\*与\*\*首次失败导致的后续失败隐藏\*\*——设计了三个紧密耦合的模块，逐轮递归地生成并验证监督信号。 ### 核心思路 论文的关键洞察在于：\*\*应由失败策略自身通过“继续飞行”来评判候选修复动作\*\*。具体而言，对于当前策略 π_k 在状态 s 处的失败，理想的修复动作应最大化该策略自身的动作价值函数：

a^(s) = argmax_a Q^(π_k)(s, a)
其中 Q^(π_k)(s, a) 定义为执行动作 a 后\*继续遵循 π_k ** 的期望回报。由于这一价值完全由策略自身的后续行为决定，只有让 π_k 实际继续飞行，才能可靠估计候选动作的好坏。基于此，AERORSI 在每一轮 k 中重复执行以下三个步骤： —- ### 1. 自适应失败锚定（Adaptive Failure Anchoring, AFA） 为克服“首次失败终止”导致的后续失败不可见问题，AFA 负责**在当前策略 π_k 的飞行轨迹中，以多时间尺度定位需要修复的状态**。 - **多偏移探针（Multi-offset Probes）**：对于每一条以失败终止的训练回合，AFA 在失败点前按指数间隔（如 1, 2, 4, 8, 16 步）放置探针，记录对应的状态 s 、观测 o 和原执行动作 a^- 。近偏移捕捉直接诱因（如撞向障碍物的动作），远偏移捕捉早期错误决策（如拐入死胡同）。 - **固定预算均匀采样**：由于探针数量远超可验证预算，AFA 从中均匀抽取固定数量的锚点（Anchor），使锚点分布自动跟随 π_k 的失败分布——高频失败类型获得更多关注，而已被克服的失败不再出现。 - **自适应评估 horizon**：每个锚点被分配一个随偏移增大而增长的评估 horizon，要求候选动作必须将飞行带过原失败点。 —- ### 2. 延续验证修复（Continuation-Verified Repair, CVR） CVR 负责**构建候选动作组，并通过 π_k 自身的后续飞行进行严格验证**，将弱监督源转化为可靠标签。 #### 候选动作组构建 对于锚点状态 s ，候选组包含三类动作：

C(s) = a^- ∪ a^((i)) sim πk(· mid o)(i=1)^M ∪ P(s)

  • **原动作 a^- **：用于基线对比； - **策略采样动作**：从 π_k 中以温度 1.0 采样 M 个动作，代表策略已能生成但未选择的动作； - **规则提案 P(s) **：包括基于深度图与目标位置计算的势场避障动作、保持原前进速度的变体、以及保持航向的爬升动作。这些简单物理先验直接模仿往往有害，但经验证后可成为有效监督。 #### 延续评分（Continuation Score） CVR 恢复锚点状态 s ，执行候选 c ，随后让 π_k **贪婪地继续飞行**直至评估 horizon 或回合结束，并赋予候选如下分数：

S_k(s, c) = Delta d - λ_f I[fail] + λ_s I[success]
其中 Delta d 为朝向目标的进度， λ_f 与 λ_s 分别为失败与成功的权重。该分数是 Q^(π_k) 的有限 horizon 蒙特卡洛估计，**直接评判候选动作在策略自身行为下的长期后果**，而非仅检查下一步或短期结果。 #### 双重验证机制 由于单次延续具有随机性，CVR 通过两层检查避免偶然结果： - **再现检查（Reproduction）**：重新执行原动作 a^- ，仅当其确实在 horizon 内失败，或最佳候选以显著优势（margin m ）超越它时，才保留该锚点。 - **确认检查（Confirmation）**：对得分最高的两个合格候选分别进行**独立重飞**，接受第一个再次合格的候选作为验证修复 c^ 。 —- ### 3. 保持性修复学习（Retentive Repair Learning, RRL） RRL 负责\*将验证后的修复蒸馏入策略，同时防止在无需修复的状态上发生行为漂移**。 - **修复监督**：最大化验证修复 c^ 的对数似然。与偏好优化（DPO）不同，RRL \*不显式惩罚原动作**，因为原动作仅在特定锚点处表现较差，在其他状态下仍可能正确。 - **行为保持（Behavior Retention）**：从 π_k 的成功训练飞行中抽取无需修复的状态集合 N （覆盖早期飞行、接近目标与着陆阶段），以 π_k 自身的贪婪输出 a_k 作为目标，通过交叉熵损失保留其正常行为。 - **修复回放（Repair Replay）**：从第二轮开始，以比例 rho 回放上一轮验证的修复，防止遗忘已学知识。 综合上述组件，第 k 轮的损失函数为：

Lk = (1 - λ_n) E(D)k[CE(c^*)] + λ_n E(N)[CE(ak)]
其中 D_k 以概率 1-rho 抽取本轮验证修复、以概率 rho 抽取上轮修复。学生网络从 π_k 初始化，仅训练视觉合并层（Visual Merger）与 LoRA 参数，冻结视觉编码器与语言模型主体，训练后得到 π(k+1) 。 —- ### 递归闭环 三轮迭代构成了一个自我改进的闭环： 1. **失败迁移**：每一轮修复了当前策略暴露的失败，但首次失败的消除会揭示同一航线更深处的新的失败（或不同航线上的失败），因此监督信号必须在每一轮重新生成。 2. **策略能力扩展**：从规则提案中学到的修复动作会在下一轮进入策略的采样空间（即策略开始自己采样到这些曾经需要规则才能提出的动作），使递归不仅仅是强化已有行为，而是真正扩展策略的能力边界。 3. **部署等价性**：所有数据生成特权（状态保存/恢复、深度图、目标位置）仅用于训练；部署时的 π_k 仅依赖原始观测 o ，保持与初始策略完全相同的架构与推理成本。 通过上述设计，AERORSI 在 TravelUAV 上将 2B 参数策略的成功率从 46.4% 提升至 67.5%，碰撞率降低一半，且无需额外人工标注或部署时推理开销。 Q4: 论文做了哪些实验？ 论文在第4节及补充材料中开展了系统的实验验证，涵盖**基准对比、逐轮迭代分析、消融研究、案例研究及统计显著性检验**五个层面。以下按实验模块归纳。 —- ### 1. 实验设置 - **状态精确恢复困难**：AERORSI 的训练依赖 simulator 的完整状态保存与恢复（save/restore），真实无人机难以精确回到历史状态以进行验证。 - **感知域差异**：真实场景的动态障碍物、光照变化、传感器噪声与仿真不同，规则提案（如基于理想深度图的势场法）可能失效。 - **探索方向**：可研究基于视觉重定位或神经辐射场（NeRF/3DGS）的近似状态恢复，以及在真实环境中利用规则提案的鲁棒替代方案（如基于单目深度的在线建图）。 —- ### 2. 向连续动作空间与更高自由度扩展 当前策略将前进、垂直、偏航运动离散化为 99 个 bins，并附加离散的着陆动作。进一步工作可探索： - **连续控制**：将验证框架扩展至连续动作空间（如直接输出速度/角速度指令），此时规则提案的生成与候选采样策略需重新设计（如扩散模型或流匹配策略）。 - **高阶动态约束**：考虑无人机的实际动力学（加速度、姿态限制），使修复动作不仅避免碰撞，也满足物理可行性。 —- ### 3. 与强化学习的深度融合 论文框架基于近似策略迭代，但优化目标仍以模仿学习（蒸馏验证修复）为主。未来可探索： - **验证信号作为优势估计**：将 CVR 的延续评分 S_k(s,c) 用作蒙特卡洛优势估计，直接通过策略梯度（PPO/GRPO）优化策略，而非仅做行为克隆。 - **在线探索与验证结合**：在策略采样阶段引入更有目的的探索（如基于不确定性的采样），减少对规则提案的依赖，同时利用验证机制过滤有害探索。 —- ### 4. 长程导航与拓扑-语义记忆 论文发现随着轮次增加，超时失败占比上升（从 1.2% 到 6.8%），表明瓶颈从局部避障转向全局路径效率： - **拓扑地图构建**：将局部修复与全局拓扑规划结合，避免反复绕远路。 - **长期上下文记忆**：当前策略基于单步视觉-语言输入，可引入场景图记忆或历史观测摘要，以处理“先向左绕过建筑，再右转进入小巷”等长程指令依赖。 - **回环检测与重规划**：当验证发现某条路径全局低效时，触发高层重规划而非仅局部动作修复。 —- ### 5. 验证效率与样本复杂度 每轮 AERORSI 需约 100 GPU 小时，其中大量时间用于蒙特卡洛延续验证： - **学习近似价值模型**：训练一个辅助的价值网络 V(s) 来预测候选动作的长期结果，减少对实际仿真展开的依赖，仅在价值接近边界时执行真实验证。 - **自适应候选数量**：根据锚点的不确定性动态调整采样数 M 与确认检查次数，在简单失败处减少验证，在复杂失败处增加验证预算。 - **跨场景迁移验证知识**：将已验证的修复模式编码为可迁移的原语（如“遇障碍爬升”），在新环境中复用而非从零验证。 —- ### 6. 未见环境的泛化性增强 论文显示在 Unseen Map 上，SFT 初始化的 AERORSI 最终仅与 AeroDPO 持平（SR 46.2% vs 45.9%），说明递归改进难以完全弥补初始表征的泛化差距： - **多样化初始化预训练**：在更多场景与视觉域上进行跨具身预训练，提升初始策略 π_0 的表征泛化性。 - **自动课程生成**：根据当前策略的瓶颈动态调整训练路线分布，在超时问题突出时增加长程航线权重，而非均匀采样。 - **分层修复**：高层策略决定“绕行/爬升/等待”等模式，低层策略控制具体动作，CVR 分别在两层进行验证。 —- ### 8. 理论收敛性与安全性分析 - **递归收敛条件**：论文观察到增益随轮次递减（11.2 → 8.4 → 1.5 点），但尚未给出收敛性保证。可建立近似策略迭代的误差界，分析验证 horizon、采样数 M 与策略改进下界的关系。 - **人机协同验证**：虽然论文强调无需人工标注，但在关键安全场景下，可将 CVR 的验证结果提交给人类操作员进行稀疏审核，形成“自动验证为主、人工审核为辅”的混合监督。 Q6: 总结一下论文的主要内容 该论文提出 **AERORSI**，一种面向空中视觉-语言导航（Aerial VLN）的递归自我改进框架，使无人机策略能够无需额外人工标注地从自身失败中学习并持续提升。 —- ### 1. 研究背景与核心问题 现有视觉-语言-动作（VLA）模型虽能将视觉观测与自然语言指令映射为飞行动作，但在闭环飞行中仍频繁因碰撞、偏离目标或陷入死局而失败。根本原因在于**模仿学习中的分布不匹配**（distribution mismatch）：策略在部署时会到达专家演示未覆盖的状态，误差沿轨迹累积。纠正这些失败需要获取**修复动作**（repairs），即在策略自身实际到达的失败状态上避免失败的动作，但现有方法面临三重障碍： - 人工专家标注成本极高，难以规模化； - 自动合成的修正（如基于碰撞回滚、参考路径）未验证当前策略自身能否执行； - 强化学习仅提供回合级奖励，缺乏动作级监督信号。 —- ### 2. 核心洞察 论文的关键观点是：**应由失败的策略自身通过“继续飞行”来评判候选修复动作**。在状态 s 处，理想的修复动作应最大化策略 π_k 自身的动作价值函数：

a^(s) = argmax_a Q^(π_k)(s, a)
其中 Q^(π_k)(s, a) 由执行 a 后\*继续遵循 π_k ** 的期望回报定义。由于该价值完全取决于策略自身的后续行为，只有让 π_k 实际继续飞行，才能可靠估计候选动作的好坏。 此外，空中导航存在特殊困难：**回合在首次失败时即终止**，导致后续失败被隐藏。因此随着早期失败被修复，航线深处的新失败才会暴露，监督信号必须在每一轮**重新生成**，递归成为必需。 —- ### 3. 方法：AERORSI 框架 AERORSI 在每一轮迭代中执行三个模块： #### (1) 自适应失败锚定（AFA） - 对每条以失败终止的训练轨迹，在失败点前按指数间隔（1, 2, 4, 8, 16 步）放置**多偏移探针**，捕捉从直接诱因到早期错误决策的多时间尺度失败原因。 - 以固定预算均匀采样探针作为**锚点**（Anchor），使监督自动跟随当前策略的失败分布，已被克服的失败不再获得锚点。 #### (2) 延续验证修复（CVR） - **候选组构建**：对每个锚点，候选动作包括原失败动作 a^- 、从 π_k 采样的 M 个动作，以及基于深度图和目标位置生成的**规则提案**（势场避障、保持前速、爬升等）。 - **延续评分**：恢复锚点状态，执行候选 c ，随后让 π_k **贪婪继续飞行**至评估 horizon，按以下公式评分：

S_k(s, c) = Delta d - λ_f I[fail] + λ_s I[success]
该分数是 Q^(π_k) 的蒙特卡洛估计，直接评判候选在策略自身行为下的长期后果。 - **双重验证**：通过**再现检查**（确认原动作确实失败）与**确认检查**（最佳候选在独立重飞中再次合格），避免单次仿真的随机性，将弱监督源转化为可靠标签。 #### (3) 保持性修复学习（RRL） - **修复监督**：最大化验证修复 c^ 的似然，但不显式惩罚原动作（避免在正常状态上产生副作用）。 - \*行为保持**：从 π_k 的成功飞行中抽取无需修复的状态，以 π_k 自身输出为目标，防止策略在正常飞行中漂移。 - **修复回放**：从第二轮起以一定比例回放上轮修复，防止遗忘。 综合损失函数为：

Lk = (1 - λ_n) E(D)k[CE(c^*)] + λ_n E(N)[CE(a_k)]
—- ### 4. 实验结果 在 **TravelUAV** 基准上的主要结果： - **SFT 初始化**：三轮递归将 2B 参数策略的成功率从 **46.4% 提升至 67.5%**，碰撞率降低近一半，较相同初始化的 AeroDPO（56.9%）高出 **10.6 个百分点**。 - **DPO 初始化**：在已优化的 AeroDPO 策略上进一步提升至 **69.9%**，证明该方法可与现有后训练技术互补。 - **失败演化分析**：随着轮次增加，碰撞与偏离目标显著减少，但超时占比上升，表明瓶颈从局部避障转向全局路径效率。 消融实验验证了： - **策略自身验证**是将规则提案等弱监督转化为有效信号的关键（未经验证的规则提案反而损害性能）； - **规则提案与策略采样**互补，且从规则中学到的修复会进入下一轮策略的采样空间，实现能力扩展； - **递归必要**：失败点在训练路线上显著迁移（中位距离达 40 m），因此每轮必须重新锚定；直接复用旧标签效果较差； - **行为保持**对防止正常飞行漂移至关重要。 —- ### 5. 主要贡献 - **识别闭环飞行中自我改进的三大挑战**（动作价值依赖后续策略、首次失败隐藏后续失败、策略无法采样所需动作），并证明让策略自行验证修复可将采样动作乃至简单规则提案转化为可靠监督。 - **揭示递归的动态机制**：验证后的修复持久有效，但失败位置随策略改进而迁移；同时规则提案的修复被内化至策略采样分布，使递归既是修复也是能力扩展。 - **提出 AERORSI 框架**，在 TravelUAV 上达到新的最先进水平，无需额外人工标注，且部署时保持与初始策略完全相同的架构与推理成本。 Q7: 想要进一步了解论文 以上只是了解一篇论文的几个基本FAQ。如果你还想与Kimi进一步讨论该论文，请点击 这里 为你跳转Kimi AI网页版，并启动一个与该论文相关的新会话。

6. Duopra: From Full-Duplex Conversation to Full-Duplex Agency

Abstract:Full-duplex interaction models exhibit strong conversational agency, enabling natural, low-latency turn-taking, backchannels, and interruptions. However, completing tasks further requires task agency: timely tool invocation and argument revision following user corrections. Frontend-backend agents separate initiation from execution: the frontend decides whether and what to request, while the backend determines how. Execution can be offloaded, but unsent requests cannot be executed, and incomplete ones can misdirect the backend. On Full-Duplex-Bench v3 (FDB v3), most failures of Realtime-Venus-Audio + Harness in our streaming pipeline occur before a domain tool executes. We introduce Duopra, a full-duplex interaction model that learns task execution alongside conversational control. Duopra treats the backend as a tool, accepting a self-contained natural-language request. Direct calls and backend delegation share an action interface and requirements for faithful initiation and correct execution. Its three-stage training combines protocol SFT, full-duplex RL rewarding timely and complete execution, and projector-only repair of talker conditioning after thinker updates. With the same backend, Pass@1 rises from 4.7% to 44.7%; Duopra achieves 47.7% calling tools directly (26.0% after SFT) and 49.3% with a DeepSeek backend. It improves three FDB v1.0 takeover rates over the base model. These results show that task agency can coexist with key conversational agency.
