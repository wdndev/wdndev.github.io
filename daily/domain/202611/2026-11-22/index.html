1. LLM Complexity: Towards a Computational Complexity View of Large Language Model Inference

Abstract:Computational complexity theory offers a principled framework for characterizing the efficiency of computational problems, and Large Language Models (LLMs) can similarly be viewed as computational systems executing a structured process of input, inference-time compute, and output. In this context, the number of generated tokens emerges as a natural and directly observable proxy for inference-time compute. However, we show that the tempting analogy between LLM token length and classical time complexity does not hold. We disprove the hypothesis that inference-time token usage aligns monotonically with classical time complexity, demonstrating a fundamental divergence grounded in how LLMs actually allocate computation during inference. To this end, we introduce LLM Complexity, a new metric designed to quantify problem complexity from the perspective of LLMs by characterizing the area bounded above by the accuracy-token curve. We find that diverse LLMs induce highly consistent task rankings under LLM Complexity, indicating that the metric captures stable notions of difficulty across models. We leverage this property to construct an easy-to-hard curriculum for supervised fine-tuning, which improves accuracy while reducing token consumption. Finally, we demonstrate that LLM Complexity generalizes to real-world tasks, producing more stable cross-model correlations than human-annotated difficulty labels.

(2024) 将Transformer与LLM建模为计算系统，并借助计算理论和形式语言理论的工具分析其表达能力。 - \*\*计算普适性\*\*：Pérez et al. (2021)、Bhattamishra et al. (2020) 以及 Jiang et al. LLM推理与推理时计算扩展 - \*\*思维链（Chain-of-Thought）提示\*\*：Wei et al. (2022) 提出通过提示激发显式中间推理步骤，以提升模型在复杂任务上的表现。 - \*\*自一致性（Self-Consistency）\*\*：Wang et al. (2023) 通过采样多条推理路径并聚合最一致的答案，实现推理时计算量的扩展。 - \*\*搜索与细化策略\*\*：近期研究进一步探索了基于搜索或细化的推理时计算扩展方法，例如 Mind Evolution（Lee et al., 2025b）。 - \*\*预算感知与过度思考\*\*：Chiang & Lee (2024)、Chen et al. (2025) 以及 Damani et al. (2025) 关注了推理中的冗余“过度思考”（overthinking）现象，以及输入自适应的预算感知计算分配策略。 - \*\*与本文的区别\*\*：不同于上述聚焦于推理机制或采样策略的工作，本文旨在\*\*量化准确率如何在受限token预算下随计算量扩展\*\*，并将这种预算–准确率关系凝练为任务级复杂性度量，以支持跨任务比较与课程学习设计。 ### 3. 面向LLM的问题难度定义 - \*\*外部定义的难度\*\*：Ding et al. (2024) 与 Zhou et al. (2026) 从一组求解者的观察成功率等外部行为指标出发，定义任务难度。 - \*\*内部定义的难度\*\*：Zhu et al. (2025) 从目标LLM的隐藏表示（hidden representations）中推断模型感知的难度（model-perceived hardness）。 - \*\*与本文的区别\*\*：本文将LLM视为计算系统，从复杂性理论的视角出发，以推理时的\*\*token消耗作为操作性资源度量\*\*，推导出一种跨模型一致的任务难度概念，而非依赖人类标注或模型内部表示。 Q3: 论文如何解决这个问题？ 论文通过\*\*定义新的运作性度量指标、建立标准化评估协议、验证其稳定性并展示下游应用\*\*来解决这一问题。具体技术路线如下： --- ### 1. 提出核心度量：LLM Complexity 论文引入了 \*\*LLM Complexity\*\*，将其定义为\*\*准确率–token预算曲线上方的面积\*\*。该度量的核心思想是：若一项任务在极紧的token预算下即可达到高准确率，则其对LLM而言复杂度较低；反之，若需大量token才能逐步提升准确率，则复杂度较高。 形式化地，对于任务 c 和问题规模 n ： - 首先在对数预算空间 B = b_1, dots, b_K 中测量不同预算下的准确率 Acc(c, n, b) ； - 利用梯形法则计算曲线下面积（称为\*\*推理效用\*\*，Inference Utility）：

U(c, n) = ∑(i=1)^(N-1) Acc(c, n, log b_i) + Acc(c, n, log b(i+1))2 · (log b_(i+1) - log b_i)

  • 对该面积进行归一化：
    U(c, n) = (U(c, n)) / (log b_(max) - log b_min), quad U(c, n) ∈ [0, 1]
  • 最终，LLM Complexity 定义为：
    C(c, n) = 1 - U(c, n)
    C(c, n) 越大，表示该任务需要消耗更多的推理时间token才能达到同等准确率，即任务越复杂。使用**对数预算空间**可避免大token预算在面积计算中过度主导。 —- ### 2. 建立标准化的预算截断评估协议 为确保测量反映的是**边际计算量**而非采样方差，论文采用**前缀截断（prefix-truncation）**与**预算强制（budget forcing）**协议： - 对每个问题实例，首先生成一条最长的推理轨迹（ b_(max) = 16,000 tokens）； - 在每个预算 b ∈ B 处截断该轨迹，并提示模型基于截断前缀继续作答； - 在不同预算下评估同一推理过程的前缀，从而精确记录准确率随可用token量的变化。 该协议确保了 C(c, n) 捕捉的是模型在特定计算资源下的实际解题能力，而非因多次采样带来的随机波动。 —- ### 3. 验证指标的关键性质 论文从三个维度验证了 LLM Complexity 的可靠性： - **跨模型一致性**：在12个算法任务上评估5个来自3个不同模型家族的LLM。实验表明，基于 C(c, n) 的任务排序在模型间具有高度的 Spearman’s rho 与 Kendall’s τ_b 相关性，优于基于输出长度、峰值准确率或达到90%峰值所需预算等启发式基线。 - **提示鲁棒性**：在多种提示变体下（如移除“逐步推理”指令、要求简洁回答、修改续写提示、改变输出格式等），LLM Complexity 诱导的任务排序保持稳定，而基于输出长度的基线在 `no_step` 等设置下显著波动。这表明该指标捕获的是任务本身的推理难度，而非提示驱动的表面 verbosity。 - **对传统复杂性的解构**：论文进一步将 LLM Complexity 与经典计算复杂性（输出长度、辅助空间复杂度、时间复杂度）进行线性分解。结果显示，**输出长度**在解释 LLM Complexity 时权重最高，而经典最坏情况时间复杂度的权重较低，证实了传统复杂度与LLM推理行为之间存在本质差异。 —- ### 4. 下游应用：基于复杂度的课程学习 利用 LLM Complexity 的跨模型稳定性，论文设计了一种**由易至难的课程学习（Curriculum Learning）**策略： - 使用大模型（NEMOTRON-253B）生成的推理轨迹作为监督信号，对较小的学生模型（QWEN3-1.7B）进行SFT； - 为每个训练样本赋予基于复杂度的采样权重：

s(c, n) = exp(-(C(c, n)) / (τ))
其中 τ 为温度参数，并在训练过程中线性退火，使模型早期集中于低复杂度（简单）样本，后期逐渐接触高复杂度（困难）样本； - 与基于运行时间、输出长度、预算基线或随机排序的课程相比，基于 LLM Complexity 的课程在**已见算法**上取得了最高准确率，并在**未见算法**上展现出更强的泛化能力，同时**降低了推理时的token消耗**。 —- ### 5. 向真实世界任务泛化 为验证指标在真实场景的有效性，论文将 LLM Complexity 应用于两个真实世界基准： - **DeepMath**：数学竞赛级问题集，含人类/GPT-4o标注的难度标签。结果显示 LLM Complexity 在不同模型间具有显著一致性，但与人类标注难度几乎无关，表明其捕获的是LLM特有的推理计算维度，而非人类感知难度。 - **RuleArena**：涵盖航空行李费、NBA交易和税务规则的现实推理任务。LLM Complexity 在此类任务上依然保持了最强的跨模型排序一致性，证明其泛化能力。 —- ### 总结 整体而言，论文的解决方案并非试图将LLM强行拟合进经典复杂性理论框架，而是**从LLM自回归推理的运作特性出发**，以token预算为资源单位，通过**准确率–预算曲线的面积**建立了一种新的、模型感知的问题复杂性度量，并围绕该度量构建了完整的评估、验证与应用体系。 Q4: 论文做了哪些实验？ 论文围绕“LLM Complexity”这一核心指标展开，设计了系统性实验以验证其动机、性质与实用性。实验可归纳为以下六大类： —- ### 1. 核心假设验证：Token Usage 与经典时间复杂性的错配 为检验“LLM推理token用量是否随经典最坏情况时间复杂性单调增长”这一假设，论文在受控环境下进行了跨任务、跨模型的对比实验。 - **任务**：12个经典算法问题（如排序、最大子数组、子集和、背包、最长公共子序列等），每个任务覆盖10个问题尺寸（ n ∈ 10, 20, dots, 100 ）。 - **模型**：NEMOTRON-49B、NEMOTRON-253B、GPT-OSS-20B、GPT-OSS-120B、QWEN-235B。 - **协议**：要求模型逐步推理（不使用外部工具），记录生成token长度，并在任务层面取平均。 - **分析**：将基于token用量的任务排序与基于经典最坏情况时间复杂性的排序进行比较，计算 Spearman’s rho 与 Kendall’s τb 。 - **关键结果**（Table 1）：所有模型的相关性均极低（如 NEMOTRON-253B 的 Spearman’s rho = 0.008 ）。此外，图1提供了两个具体反例： - 对于规模80，排序（ O(n log n) ）达到50%准确率所需token预算高于NP完全的子集和； - 四数之和最近值（Four Sum Closest）的准确率随问题规模增加并未单调下降。 —- ### 2. 4. Physics of Language Models: Part 4.2, Canon Layers at Scale where Synthetic Pretraining Resonates in Reality

Abstract:Do standard benchmarks see the architectural differences that matter? Q: 这篇论文试图解决什么问题？ 这篇论文试图解决的核心问题是：\*\*标准基准测试是否真正能量化那些具有实质意义的架构差异，以及基于这些基准的架构比较是否会掩盖模型在基本上下文推理能力上的关键缺陷。\*\* 具体而言，该研究围绕以下几个层面展开： ### 1. 实验灵敏度与架构差异的可检测性 论文指出，在学术规模的预训练（如1.3B参数/100B token）中，即使经过仔细调优，不同架构（如Transformer与各类线性模型）之间的差异往往会消失在随机种子噪声之中。这引发了一个根本性问题：当受控比较产生相似分数时，结论是架构同等有效，还是实验本身缺乏区分度？因此，论文试图通过更大规模的预训练（1.3–8B参数，1–2T token）来验证，\*\*那些在小规模下不可见的架构改进（如Canon层）在放大规模后是否依然有效且可测量\*\*。 ### 2. 合成Playground预测的外推有效性 在先前的研究（Part 4.1）中，作者提出了一个合成预训练 playground，能够在不到100M参数的规模下预测架构差异（例如Canon层的增益、线性模型的检索缺陷）。论文试图验证这些在廉价合成环境中发现的规律，\*\*是否能在耗资巨大的真实大规模预训练（单次8B/1T运行成本约10万美元）中得到复现\*\*，从而确定小规模合成实验的预测价值。 ### 3. 线性模型中“额外机制”的真实贡献 线性架构（如Gated DeltaNet的delta rule、Mamba2的选择性状态空间更新）通常被宣传为比最简单的门控线性注意力（GLA）更强大。论文试图剥离这些复杂机制的包装，通过严格的参数对齐（strict alignment）和引入低秩输出门（GLA5/GDN2），来回答：\*\*这些额外机制是 genuinely 提升了记忆与推理能力，还是仅仅在提供局部token混合（horizontal mixing）\*\*——后者可以通过一个极轻量的Canon层（增加不到0.2%参数）直接实现。 ### 4. 标准基准测试的盲区 论文发现，线性模型在标准知识/常识基准（如MMLU、HellaSwag）上可以与Transformer匹敌甚至超越，但在更基础的上下文技能上却表现出显著缺陷。因此，研究试图暴露并量化\*\*标准基准无法捕捉的两大关键弱点\*\*： - \*\*上下文信息检索（Result 6）\*\*：线性模型在仅有500个干扰token的背景下，可靠检索显式陈述信息的能力急剧下降，而Transformer几乎不受影响。 - \*\*多跳推理（Result 7）\*\*：即使在8B/1T规模下，所有模型（包括Transformer）在简单的两跳推理问题上仍接近随机猜测水平，这表明\*\*当前预训练范式可能并未有效培养基础推理能力\*\*。 ### 5. 预训练数据配方的启示 基于上述缺陷，论文试图推导对实践者的直接建议：如果基础模型在预训练阶段未能掌握基本的上下文推理，那么在后训练阶段（post-training）弥补这些技能将极为困难。因此，研究主张\*\*应在预训练早期就引入上下文推理示例（如检索和多跳问题）\*\*，而非将其留到中期训练或后训练阶段。 简言之，该论文不仅比较了架构，更深刻质疑了\*\*当前架构研究依赖的评估范式本身\*\*，并论证了合成可控任务在揭示真实架构差异方面，有时比大规模真实预训练更具分辨力。 Q2: 有哪些相关研究？ 根据论文第7节（Related Work）及全篇引用，相关研究可归纳为以下六个方向： ### 1. 线性序列架构（Linear Architectures） - \*\*代表性模型\*\*：Gated Linear Attention（GLA）

h’t = w_0 odot h_t + w_1 odot h(t-1) + w2 odot h(t-2) + w3 odot h(t-3), quad w0,dots,w_3 ∈ R^m
采用残差形式 $h’_t = h_t + conv1d(
h_t, h(t-1), h(t-2), h(t-3)
) ，仅增加 0.07–0.15% 参数。实验证明，Canon 在 1.3–8B 的每一个设置中均持续提升 Transformer，并在 8B 规模下节省约 30% 的预训练 token（Result 2）。 - 低秩输出门（GLA5 / GDN2）：原始 GLA 与 GDN 的全秩输出门 G ∈ R^(dv × d)$ 可占循环层 1/3 参数。论文将其替换为低秩分解：

learnability is everything.** 具体而言： - **水平混合主导架构复杂度**：通过为 GLA5、GDN2、Mamba2 均添加 Canon，发现 GLA5（最简单的门控累积）追平了 GDN2（delta rule）并超越 Mamba2（selective SSM）。这表明 GDN2 与 Mamba2 的额外机制在训练中的实际收益，很大程度上不过是提供了与 Canon 类似的**短程局部混合**（Result 5）。 - **存在性不等于可习得性**：架构或许能表达更复杂的计算，但预训练优化器未必能高效发现。低秩门控之所以能提升性能，正是因为它假设全秩门在训练中仅学习到简单的缩放/抑制模式。 —- ### 6. 提出预训练数据策略 基于“一旦预训练结束，后训练难以补全缺失技能”的先前研究（Parts 2.2 与 3.2），论文进一步提出： - **在预训练早期即引入上下文推理示例**（如检索、多跳问题），而非将其留至中期训练或后训练。这样可使模型内部状态在吸收知识的同时就开始为推理做准备，避免事后重塑的昂贵代价。 —- 综上，论文的解决方案并非提出一个单一的“更优模型”，而是通过**严格的规模化解耦实验**、**从合成到真实的跨尺度验证**、以及**针对基础技能的定向探针任务**，重新界定了架构比较的可信标准，并揭示了标准基准评估体系下的系统性盲区。 Q4: 论文做了哪些实验？ 论文进行了 **64 组从头预训练（from-scratch pretraining runs）**，覆盖三种参数规模（1.3B、3B、8B），在 1–2T 的 Nemotron-CC 高质量语料上训练，并对 Transformer 与三种线性模型家族进行系统对比。实验设计可分为以下六个层面： —- ### 1. 模型架构与规模 | 规模 | 层数 | 隐藏维度 | 注意力/循环头数 | 架构变体 | |———|———|—————|————————-|—————| | **1.3B** | 24 | 2048 | 16–32 | Llama / LlamaCanon; 5. Global Importance Estimation for KV Cache Eviction

7. The ROI of Small Examples: Optimizing In-Context Learning Under Token Budgets

Abstract:In-context learning (ICL) improves large language model performance at inference time without updating model parameters. However, these gains are not free: in practical deployments, longer prompts directly increase inference cost and latency. Overall, our results highlight demonstration granularity as an important factor in prompt design.

9. CANDID: Candidate-Driven Intervention for Disciplined Execution in Local Computer-Use Agents

Abstract:We present CANDID (Candidate-Driven Intervention for Disciplined Execution), an execution-control framework designed to enhance the reliability of local computer-use agents (CUAs) in resource-constrained settings. \*\*两阶段循环检测门控\*\* - \*\*第一阶段（规则检测）\*\*：使用轻量级启发式规则比较当前提议动作与滑动窗口内的近期执行历史（受窗口大小 w 、最小重复次数 r 、目标坐标容差 τ 控制）。若检测到如 \`repeated\_action\_type\_and\_target\`、\`repeated\_exact\_text\_or\_key\_action\` 或 \`repeated\_cyclic\_action\_pattern\` 等模式，则标记为潜在循环。 - \*\*第二阶段（模型确认）\*\*：仅对规则标记的罕见情况调用本地模型，基于当前截图与轨迹独立确认代理是否真正陷入无进展循环（\`loop\_detected=true\` 或 \`strategy\_signal=SWITCH\`）。此举将高成本的模型判断约束在必要时刻，避免过度干预正常执行。 - \*\*恢复候选生成\*\* 一旦循环被确认，框架令同一本地模型从当前环境状态额外采样 k=4 个可执行候选动作，利用其在重复采样下仍能产生多样动作的能力。 - \*\*结构化过滤与选择\*\* 对生成的候选池进行硬约束过滤： - 剔除畸形或不可执行动作； - \*\*禁止\*\*在循环恢复期间选择 \`DONE\`； - \*\*排除\*\*与检测到的循环模式匹配的候选（例如同类型且坐标在容差 τ 内的动作）； - 合并完全重复的候选。 过滤后： - 若无有效候选，回退至原始提议动作； - 若仅剩一个候选，直接执行； - 若存在多个候选，由代理基于任务指令与近期轨迹从中选择最优动作。 --- ### 2. 全票一致DONE门控（Unanimous DONE Gating） 该模块针对\*\*过早虚假成功\*\*失败模式，在代理提议终止时引入保守的终止审批机制。 - Cognitive science suggests this generalization stems from a top-down generative inference strategy. In contrast, state-of-the-art 3D reconstruction neural networks typically rely on amortized, feedforward inference. While fast, this pattern-matching approach degrades when faced with out-of-distribution (OOD) scene conditions unseen during training. Inspired by the generative nature of human vision, we propose Infer3D, an inverse generative modeling framework that recovers the latent variables of a generative model to best match the monocular input. To prevent degenerate flat outputs, we couple the generative image prior with a frozen 3D lifting network that constrains the optimization space to a valid, multi-view-consistent 3D manifold. Across a variety of controlled synthetic and real-world tasks, Infer3D demonstrates superior OOD reconstruction accuracy compared to feedforward networks trained on equal or larger datasets. Furthermore, mirroring how human perception requires more time to process confusing stimuli, we introduce an adaptive inference strategy that expends more test-time compute on ambiguous OOD examples while efficiently routing in-distribution inputs. 其中 S 为场景几何与外观， θ 为渲染参数（如相机外参、内参或畸变参数）。 —- ### 2. 流形约束：2D生成先验 + 冻结3D提升网络 直接对3D场景先验 p(S) 建模是困难的。为此，论文引入了两个解耦且**冻结**的网络，将优化变量约束在有效的多视图一致流形上： - **生成图像先验 G(z) **：一个从潜在空间解码到2D图像的生成模型（如 StyleGAN2 或 Diffusion Autoencoder）。它确保输入给3D提升网络的图像始终位于分布内（in-distribution）流形上。 - **2D到3D提升网络 Phi **：一个预训练的前馈网络（如 Splatter Image 或 CATSplat），将2D图像映射为3D高斯表示。该网络在推断时完全冻结。 通过参数化 S = Phi(G(z)) ，场景先验被隐式定义为”由有效2D图像提升而来的3D结构”。推断问题转化为对潜在码 z 和渲染参数 θ 的联合优化：

z, θ = argmax(z, θ) log p(I(OOD) mid S, θ)(Likelihood) + log p(z)(Latent Prior) + log p(θ)(Rendering Prior)
在实践中，负对数似然由可微渲染器 R （3D高斯溅射）计算的重建损失 L 实现，而潜在先验通过二次惩罚 |z - z(∈it)|_2^2 近似，防止优化偏离有效流形。 —- ### 3. 非凸优化与粒子滤波 由于能量景观高度非凸，论文采用**多起点粒子滤波策略**（Algorithm 1）避免局部最小值： - **初始化**：生成 R 个粒子，每个粒子包含随机采样的潜在码 z_r 和渲染参数 θ_r 。若存在编码器（如 DiffAE），则用一个前馈初始化替换随机粒子。 - **迭代优化**：每个粒子独立通过梯度下降更新，损失为重建误差与潜在正则项之和：

其中 I_r = R(Phi(G(z_r)), θ_r) 。 - **剪枝**：按预设 schedule（如第3、122、302次迭代）淘汰高误差粒子，逐步将种群从数百个剪至个位数，最终保留最优假设。 —- ### 4. 针对三类OOD域偏移的模块化适配 框架的灵活性体现在仅需重新定义 θ 、 p(θ) 和似然函数即可处理不同 OOD 条件： #### (1) 未见相机视角（OOD Camera Poses） - In a single forward pass, IDWorld imagines these counterfactual features under shared canonical conditions, such as the same outfit, a fixed view, or a bare silhouette, without rendering any pixels. Compared with explicit imagination in pixels, this latent imagination keeps nearly the same accuracy while being over 11x faster, at 5.9 ms per frame. Since each imagined condition has its own strengths, IDWorld then fuses them adaptively, weighting each condition for every probe-gallery pair. Extensive experiments show that IDWorld achieves state-of-the-art results on CCPG and CCGR-MINI, outperforms the compared methods on MEVID, and generalizes best to CASIA-B* and SUSTech1K, with the best mAP on CCVID. These results suggest identity world models offer a simple yet effective path to robust recognition. Code will be released.
