1. The FlightFinder Occurrence Corpus: harmonising 128 aviation-safety source codes into one deduplicated cross-national accident dataset

Abstract:National aviation-investigation databases are deep but territorial; global compilations such as the Aviation Safety Network and the Bureau of Aircraft Accidents Archives are hand-curated, apply their own inclusion thresholds, and publish no per-record lineage. The FlightFinder Occurrence Corpus harmonizes 279,485 occurrences and 131,882 attached narratives from 128 source codes — national accident-investigation authorities, occurrence-reporting systems and four global compilations. Records are mapped into one schema; each normalized record reduces to exactly one key from an ordered ladder — event signature, registration and date, rounded position and date, or source and native identifier — so a missing field never creates a link, and the key is the occurrence identifier. Records the ladder cannot reach are scored in a blocked pass into an explicit merge table and applied only within an automatically approved score band or after a person confirms them. Field conflicts follow a documented source ranking; one provenance row per contributing source — its native identifier and URL — is retained, with attribution and licence terms per source code. Linkage error is measured on five adjudicated samples totalling 200 pairs. A recorded uniform random draw of 60 from the 3,441 merges the automatic band applies as it ships found no error; the exact two-sided 95% Clopper-Pearson upper bound on its false-merge rate is 6.0%, or 205 pairs. The measured error covers the scored band only; the ladder’s deterministic joins are not adjudicated. The corpus has no exposure denominators and inherits the under-reporting of its sources. It is offered as a base for cross-national safety statistics, source-disagreement studies and narrative text mining; a frozen, DOI-referenced snapshot accompanies the live API.

2. Scoring Explanations Without Reading Them: Structural Shortcuts in Automated-Interpretability Evaluation Data

Abstract:Automated interpretability scores an explanation of a sparse-autoencoder (SAE) feature by asking a model to predict, token by token, where the feature fires on evaluation examples or to judge whether marked tokens fit it. We find that the evaluation data standard pipelines build can be scored without reading the explanation. On Neuronpedia’s stored fuzzing runs for 500 random GPT-2 small features, 91.3% of activating examples are cropped with the peak on the centre token, and a rule that says “yes” when the centre token is marked reaches balanced accuracy 0.979, against 0.838 for the stored LLM scorers (recomputed from the stored per-item verdicts, on marks rebuilt from the pipeline’s code); a rule reading only the mark count reaches 0.969. The cue changes form across pipelines: current delphi always marks the same slot in its fuzzing negatives, and full-context runs mark negatives with more tokens. OpenAI’s simulation benchmark lists each neuron’s top-activating sequences first; a rule that predicts activity on the first five scores 0.227 in pooled correlation against 0.160 for GPT-4’s published simulator (post hoc). We give closed forms for what such rules can score; show that one scorer’s simulation scores are higher on stored snippets than on natural windows but not shown to be reordered; and build windows that remove the position cue, derive but do not build negatives that remove the mark cues, and separate the sequence cue by decomposition. On natural-text windows cut at random offsets, the best fixed-offset prior shared by all features scores 0.015. On them, that scorer, a typed decision model (Jev), reaches a pooled correlation of 0.331 over 49 features, against 0.013 with shuffled explanations, and an open 8B simulator with the original read-out reads the explanation there (0.194 against 0.019). Scores should be reported beside the best explanation-free rule on the same items.

Q: 这篇论文试图解决什么问题？ 这篇论文针对的是\*\*自动化可解释性（automated interpretability）评估数据中的结构性捷径（structural shortcuts）问题\*\*。具体而言，论文揭示了当前主流评估流程所构建的数据本身就携带了与解释文本无关的构造性线索，使得评分规则无需真正“阅读”解释即可达到甚至超越大型语言模型评分器的表现，从而导致现有分数难以成为解释质量的可靠证据。 核心问题可分解为以下几个方面： - \*\*评估数据构造泄露答案\*\*：在稀疏自编码器（SAE）特征的自动解释评估中，标准流程构建的示例窗口、标记方式及序列排布携带了可预测的结构性模式。例如，激活示例的峰值常被裁剪在窗口正中央，负样本的标记位置与数量遵循固定采样规律，而模拟任务的序列按激活强度排序。 - \*\*无解释基线即可击败现有评分器\*\*：利用上述构造线索，仅依赖项目结构（如“若中央token被标记则回答yes”或“预测前五个序列激活”）的简单规则，在多个公开流水线（Neuronpedia、delphi、OpenAI发布的数据）上取得了高于存储的LLM评分器的分数。例如，在Neuronpedia的500个随机特征上，中央标记规则的平衡准确率达到0.979，而存储的LLM评分器仅为0.838。 - \*\*现有分数难以证明解释被真正理解\*\*：由于构造线索的存在，评分器的高分可能源于对数据格式的利用，而非对解释语义的把握。论文指出，只有当评分器在同一批数据上击败所有不读解释的预设规则，并且打乱解释后分数显著下降时，该分数才能构成对解释质量的证据。 - \*\*缺乏去除线索后的标准化评估\*\*：论文进一步构建并验证了去除位置线索（随机偏移自然窗口）、标记线索（匹配正负样本标记分布）及序列线索（分解序列间与序列内贡献）的方法，证明在清洁数据上，评分器依然能够读取解释，从而区分真正的解释能力与结构性投机。 简言之，该论文试图纠正自动可解释性领域中对评分数据的盲目信任，主张\*\*在报告任何解释得分时，必须同步报告同批数据上最优的无解释规则分数，并采用去除构造捷径的评估协议\*\*，以确保评估指标真实反映模型对特征解释的理解程度。 Q2: 有哪些相关研究？ 根据论文第2节（Related Work），相关研究可归纳为以下五个方向： ### 1. 自动解释与单元评分 该方向涵盖从视觉网络到语言模型神经元的自动描述与评分方法。 - \*\*视觉网络\*\*：Bau 等人 (2017) 提出网络解剖学（Network Dissection）量化深度视觉表示的可解释性；Hernandez 等人 (2022) 与 Oikarinen & Weng (2023) 进一步探索自然语言描述深层视觉特征的方法。 - \*\*语言模型神经元\*\*：Bills 等人 (2023) 提出“先解释后模拟”（explain-then-simulate）范式，用于语言模型神经元的自动解释。 - \*\*稀疏自编码器（SAE）特征\*\*：Cunningham 等人 (2024)、Bricken 等人 (2023) 与 Templeton 等人 (2024) 将该范式迁移至 SAE 字典特征；Paulo 等人 (2025) 将其扩展至数百万特征，并引入检测（detection）与模糊测试（fuzzing），发布为 \*\*delphi\*\* 工具；Neuronpedia 则运行该代码分支并存储评分结果。 - \*\*辅助技术\*\*：Choi 等人 (2024) 微调解释器与模拟器；Singh 等人 (2023) 与 Gur-Arieh 等人 (2025) 改进解释质量；Shaham 等人 (2024) 构建多模态自动解释智能体。 ### 2. 解释分数与 SAE 评估 该方向关注现有评估指标的可靠性与局限性。 - \*\*模拟分数的局限\*\*：Huang 等人 (2023) 指出高模拟分数可能与解释遗漏单元因果角色共存；Bolukbasi 等人 (2021) 发现解释依赖于用于发现顶部激活的数据分布。 - \*\*验证方法\*\*：Schwettmann 等人 (2023) 在具有已知描述的函数上检验解释方法；Kopf 等人 (2024) 生成概念数据；Oikarinen 等人 (2025) 提出统一框架与合理性检查。 - \*\*基准与诊断\*\*：Heap 等人 (2026) 发现自动可解释性指标难以区分训练与随机 Transformer；Puri 等人 (2025) 的 FADE 框架分离失败模式；Makelov 等人 (2025)、Karvonen 等人 (2025) 与 Kantamneni 等人 (2025) 引入基于任务的 SAE 评估基准。 - \*\*无解释评估\*\*：Paulo & Belrose (2026) 在不生成解释的情况下评估 SAE 可解释性；van der Ben 等人 (2026) 发现流水线设置（语料、示例抽取）对分数与特征排名的影响超过架构差异。 ### 3. 评估数据中的捷径与泄露 该方向指出基准测试常存在忽略预期信号的替代解决方案。 - \*\*注释伪影与假设基线\*\*：Poliak 等人 (2018) 与 Gururangan 等人 (2018) 发现自然语言推理数据中的假设-only 基线与注释伪影。 - \*\*启发式与捷径学习\*\*：McCoy 等人 (2019) 诊断自然语言推理中的语法启发式；Geirhos 等人 (2020) 讨论深度学习中的捷径学习（shortcut learning）。 - \*\*显著性与泄露\*\*：Adebayo 等人 (2018) 对显著性图进行合理性检查；Kapoor & Narayanan (2023) 分析机器学习科学中的数据泄露与可重复性危机。 - \*\*本文定位\*\*：上述研究聚焦于文本或标签层面的泄露，而本文的“无解释规则”是针对项目构造（窗口裁剪、标记位置、序列排序）的输入-only 基线。 ### 4. Transformer 首位置效应与激活异常 - \*\*注意力汇与残差异常\*\*：Xiao 等人 (2024) 发现首个 token 作为注意力汇（attention sink）；Sun 等人 (2024) 发现其具有极大的残差值。 - \*\*位置单元\*\*：Voita 等人 (2024) 识别出纯位置神经元。 - \*\*对 SAE 的影响\*\*：使用序列开始（BOS）token 训练的 SAE 在应用时若缺少 BOS，会将首个真实 token 误判为异常值，导致激活分布偏移。 ### 5. 类型化决策模型与廉价评判器 - \*\*LLM 作为评判器\*\*：Gilardi 等人 (2023)、Ziems 等人 (2024) 与 Zheng 等人 (2023) 将 LLM 用于文本注释与评判；Wang 等人 (2024) 发现 LLM 评判存在位置偏差。 - \*\*成本感知路由\*\*：Chen 等人 (2024)、Ding 等人 (2024) 与 Ong 等人 (2025) 研究如何将简单查询路由至更廉价的模型。 - \*\*编码器式评分\*\*：Schick & Schütze (2021)、Devlin 等人 (2019)、Warner 等人 (2025) 与 Marone 等人 (2026) 利用编码器以完形填空方式对预定义选项评分。 - \*\*类型化决策模型（Typed Decision Models）\*\*：Ibrahim & Zaki (2026) 发现其比前沿 LLM 更廉价但准确度较低；Convai Innovations (2026) 的 Laya 是开放实现；Sun 等人 (2026) 表明此类模型的决策头可能跟随选项名称而非绑定的评分标准。 - \*\*校准\*\*：Guo 等人 (2017)、Zhao 等人 (2021) 与 Kadavath 等人 (2022) 研究模型与格式对校准的影响。 Q3: 论文如何解决这个问题？ 论文通过\*\*识别结构性捷径、建立无解释基线、重构评估数据\*\*以及\*\*提出标准化报告规范\*\*四个层面解决该问题。 ### 1. 识别并量化三个结构性线索 论文系统分析了四个公开流水线中的数据构造，定位了三类可被无解释规则利用的线索，并给出其闭式表达或严格上界： - \*\*位置线索（Position cue）\*\*：Neuronpedia 存储的激活示例为 17-token 窗口，峰值固定在中心 token（第 9 位）。仅预测中心位置的固定先验在模拟任务中达到 pooled correlation 0.732 ；在模糊测试中，"若中心 token 被标记则回答 yes" 的规则达到 balanced accuracy 0.979 ，远超存储的 LLM 评分器（ 0.838 ）。 - \*\*标记线索（Mark cues）\*\*：模糊测试的负样本通过固定种子采样标记，导致标记位置与数量分布与正样本可区分。仅读取标记数量或固定槽位的规则在 GPT-2 数据上达到 0.969 ，在 Gemma 数据上达到 0.981 。 - \*\*序列线索（Sequence cue）\*\*：OpenAI 的模拟基准将高激活序列排在前面，利用序列顺序即可达到 pooled correlation 0.227 ，高于 GPT-4 发布模拟器的 0.160 。论文通过\*\*序列均值预言机（sequence-mean oracle）\*\* eta 给出了所有序列内常数规则的上界（Proposition 1(c)）。 ### 2. 建立"无解释基线"原则 论文提出，任何解释评分只有在\*\*同一批数据上击败所有预设的无解释规则\*\*时，才能构成对解释质量的证据。具体而言，需报告配对指标：

(score(f), max_(g ∈ G) score(g))
其中 G 为仅依赖项目构造（token 位置、标记集合、序列归属）的规则族。若评分器未超过该基线，或打乱解释后分数未降至基线附近，则分数无效。 ### 3. 构建去除线索的评估数据 论文设计并验证了三种去除或分离线索的构造方法： - **去除位置线索**：在 OpenWebText 上构建**随机偏移自然窗口**（random-offset natural windows），将峰值位置均匀随机化。此时最佳共享偏移先验仅得 0.015 ，中心先验近乎归零（ 0.003 ），彻底消除了位置捷径。 - **去除标记线索（推导）**：依据 Proposition 3，若负样本的标记集合从与正样本相同的分布中独立抽取（如将正样本标记一对一重排给负样本），则任何仅依赖标记的规则期望平衡准确率严格为 0.5 。论文推导了该构造但未实际实施。 - **分离序列线索**：利用方差分解（Proposition 1(b)）将模拟分数拆分为**序列内**（within-sequence）与**序列间**（between-sequence）贡献：

r(a, a) = rw √1-eta^2√1-eta^2 + r_b eta eta
其中 eta 为序列均值预言机。由此可区分评分器是真正在序列内 token 级别匹配激活，还是仅利用了序列间的均值差异。 ### 4. 在清洁数据上验证评分器的真实能力 论文证明，当结构性捷径被移除后，评分器仍能读取解释： - Jev（Typed Decision Model） 在随机偏移自然窗口上的模拟 pooled correlation 为 0.331 ，而打乱解释后降至 0.013 ，且显著高于序列均值预言机（ eta = 0.166 ）和最佳共享偏移先验（ 0.015 ）。其得分主要来源于序列内匹配（ 0.285 ），而非序列间偏移。 - 3. The Best Second Opinion Is Right Where the Primary Is Wrong: Partner Selection for Selective Span Tagging

Abstract:A span tagger that ranks its outputs by risk can defer the riskiest ones to a person, and a second model can sharpen this ranking. Which second model should it be? Partner selection is conditional, not global: the best second opinion is the model that is right where the primary is wrong. Across eight tagger types, three seeds and three English benchmarks (576 evaluated primary-partner pairings), choosing the partner by held-out accuracy on the primary’s errors recovers 82% of the best partner’s gain, against 69-70% for span F1 or a random pick. Frozen before a fourth dataset was chosen, the rule replicated there (Spearman 0.40 vs. 0.04 for span F1). Partner value is also directional. The predictive distribution is the second opinion: hard labels discard half of a partner’s value, and scoring the served label improves 94% of pairings. Fixed before the fourth dataset was chosen, this score also replicated there. For LoRA-tuned decoders, independently trained partners beat every readout of the primary network. 4. Exposure Is Not Commitment: Double-Stratified Evaluation of Latent Monitors for Tool-Using Agents

Abstract:Tool-using language agents are vulnerable to indirect prompt injection, and a growing literature probes model internals to catch unsafe actions before they execute, with sharply conflicting results. We argue much of the conflict is an evaluation artifact, and propose a double-stratification protocol: separate injection exposure from behavioral commitment, in both the evaluation and the training population. On the primary Qwen AgentDojo grid, monitors trained on the naive mixed unsafe-versus-rest contrast mostly learn exposure: they flag exposed trajectories whether or not the agent complies, and barely predict which cases turn unsafe. Retrained on exposed cases only, the same probe families predict the model’s own unsafe tool call up to two steps early, the maximum the three-step trajectories admit (logistic AUROC 0.853, matched by a trained TF-IDF text baseline at 0.855). Mistral-7B reaches 0.896 and OLMo-2-7B 0.912; their naive contrasts learn different things: inverted exposure ranking on one, both axes on the other. Representations separate on exposure (probe 1.000 versus trained text 0.908) and where visible context is sanitized or unavailable. Training contrast alone reproduces the shape of recent pre-action-probe negative results, one candidate explanation for the conflict: the signal exists, but the model’s own zero-shot forecast and NLA verbalizations do not reliably recover it. 5. Artifact Distillation: Training-Free Transfer from Frontier to Small Language Models

Abstract:Closing the gap between frontier and smaller language models is usually approached by distillation: fine-tuning the small model (student) on a frontier model’s (teacher) outputs, which binds transfer to training compute and leaves the transferred knowledge largely opaque. We propose Artifact Distillation: a teacher solves training instances and externalizes its problem-solving procedure into an artifact bank that a student queries at inference time, with no gradient updates. Across four LiveBench tasks, a bank written by Claude Opus 4.5 lets Claude Haiku 4.5 outperform unaided Claude Sonnet 4.5 on spatial reasoning (0.707 vs. 0.647) at 60% of its cost, and reach Sonnet 4.5’s level on table joining at 89% of its cost. The same raw bank raises Qwen3.5-27B’s pooled score from 0.730 to 0.800, showing that transfer is not confined to the teacher’s model family.

\*\*知识不透明性\*\*：一旦知识被编码进模型参数，便难以检查、理解或事后修订。 为此，论文提出 \*\*Artifact Distillation（工件蒸馏）\*\* 框架，其核心解决思路是： 1. \*\*将知识外化而非内化\*\*：教师模型在解决训练任务后，把通用的解题方法、策略和检查步骤以自然语言形式写成“工件”（artifacts），存入一个可读的工件库（artifact bank）。 2. \*\*推理时检索替代训练\*\*：学生模型权重保持冻结，在推理阶段通过两阶段流程（先根据触发条件选择相关工件，再结合工件内容作答）查询该库。 3. \*\*实现可解释、可复用的能力迁移\*\*：由于工件以自然语言显式存储，转移的知识是透明、可审计且可跨模型家族复用的。 实验表明，该方案能够在部分任务上使小模型以显著更低的推理成本达到甚至超越未辅助的更大模型的表现，例如让 Claude Haiku 4.5 在空间推理任务上以 Sonnet 4.5 60% 的成本超越后者，同时同一工件库也能提升 Qwen3.5-27B 的跨家族性能。 Q2: 有哪些相关研究？ 根据论文第5节，与 \*\*Artifact Distillation\*\* 相关的研究工作可分为以下四类，论文同时阐明了自身与这些工作的核心差异： ### 1. 标准知识蒸馏（Standard Distillation） 这类方法通过监督微调（SFT）将教师能力迁移到学生模型的权重中，具体形式包括： - \*\*输出分布匹配\*\*：如 Hinton 等人提出的经典知识蒸馏，使学生模仿教师的软标签分布； - \*\*序列级蒸馏\*\*：如 Kim & Rush (2016) 的方法，让学生复制教师的输出序列； - \*\*中间表示蒸馏\*\*：如 Jiao 等人的 TinyBERT，对齐教师与学生的隐藏层表示； - \*\*推理过程蒸馏\*\*：如 Hsieh 等人的 "Distilling step-by-step" 以及 Wadhwa 等人对 CoT 增强蒸馏的探究，将教师的推理链或 rationales 作为训练目标。 \*\*核心差异\*\*：Artifact Distillation \*\*完全不更新学生权重\*\*，所有转移的知识以自然语言工件的形式外化存储，学生仅在推理时检索。 ### 2. 检索增强生成（RAG）与少样本学习（Few-Shot Learning） - \*\*RAG\*\*（Lewis 等人）：从外部语料库检索相关文本段落，再结合生成； - \*\*少样本示例\*\*（Brown 等人）：在提示中提供输入-输出样例，包括后续工作如 Rubin 等人通过检索优化示例选择。 \*\*核心差异\*\*：上述方法检索的是\*\*原始文档或已解决的实例\*\*；Artifact Distillation 检索的是\*\*教师撰写的、领域通用的解题策略与程序性指导\*\*，而非具体答案或文本片段。 ### 3. 模型路由与级联（Routing & Cascades） - \*\*FrugalGPT / RouteLLM\*\*（Chen 等人；Ong 等人）：根据查询难度或成本约束，将请求路由到不同能力的模型，或由小模型回答、大模型复核。 \*\*核心差异\*\*：路由方法决定\*\*“哪个模型”\*\*来回答问题；Artifact Distillation 的目标是\*\*让廉价模型自身变得更准确\*\*，而非依赖调用更强的模型。 ### 4. 教师撰写的指导性文本（Teacher-Written Guidance） 这是最接近的先例，但存在关键区别： | 工作 | 主要内容 | 与 Artifact Distillation 的区别 | |------|----------|-------------------------------| | \*\*TPD\*\* (Wang 等人, 2024) | 教师从\*\*学生自身的错误\*\*中提炼原则，并将其折叠进修订后的系统指令与少样本示例。 | TPD 需观察学生错误且依赖指令重写；Artifact Distillation 的教师仅从\*\*自身解题过程\*\*写工件，无需观察学生，一个库可服务多个模型。 | | \*\*RICP\*\* (Sun 等人, 2024) | 从训练错误中检索与测试问题最相近的见解（insights）。 | 同样要求学生在标注数据上先产生错误；Artifact Distillation 的工件是\*\*前瞻性、领域通用\*\*的策略，而非针对特定历史错误的复盘。 | | \*\*AutoManual\*\* (Chen 等人, 2024b) | 通过与环境交互自动生成手册，指导较小 LLM 完成任务。 | 依赖环境交互与试错；Artifact Distillation 通过一次性解决训练集并外化工件完成，无需在线交互。 | | \*\*ExpeL / AutoGuide\*\* (Zhao 等人; Fu 等人, 2024) | 从智能体（agent）的经验轨迹中提取并总结指导性规则。 | 面向长程交互与智能体学习；Artifact Distillation 面向单轮任务的问题解决程序转移。 | | \*\*基于自身错误/经验的学习\*\* (Zhang 等人; Shinn 等人; Ouyang 等人) | 模型从自身的推理错误（如 Reflexion）或经验库（如 ReasoningBank）中进化。 | 侧重自我改进与记忆积累；Artifact Distillation 是\*\*跨模型\*\*的知识转移，且工件内容由更强的教师模型撰写。 | ### 总结性区分 论文强调 Artifact Distillation 在三个层面区别于已有工作： 1. \*\*教师-学生解耦\*\*：教师写库时\*\*无需观察学生\*\*在训练数据上的表现，工件库可被同一教师生成的多个不同学生（甚至教师自身）复用，且支持跨模型家族转移（如 Claude → Qwen）。 2. \*\*触发-内容分离的两阶段推理\*\*：学生先仅根据\*\*触发器（trigger）\*\*选择工件 ID，再在独立调用中才看到工件\*\*完整内容\*\*，避免信息过载。 3. \*\*成本-精度联合评估\*\*：论文明确将“学生 + 工件库”的系统与\*\*未辅助的更强模型\*\*在\*\*准确率与推理成本\*\*两个维度上对比，证明小模型可在更低成本下追平或超越大模型。 Q3: 论文如何解决这个问题？ 论文通过 \*\*Artifact Distillation（工件蒸馏）\*\* 框架解决该问题，其核心在于将教师模型的解题程序外化为自然语言工件库，供冻结权重的学生模型在推理时检索。具体流程分为\*\*库构建\*\*与\*\*库使用\*\*两大阶段，详述如下： --- ### 1. 问题形式化 给定教师模型 T 、学生模型 S 、以及包含训练集 D_(train) 与验证集 D_(eval) 的任务。转移效果定义为：学生在 D_(eval) 上的准确率，在可访问工件库相对于无库时的变化量。 --- ### 2. 工件库的构建（教师阶段） #### 2.1 初始解题与工件撰写 对 D_(train) 中的每个实例，教师 T 首先独立求解问题；随后，针对其解题过程撰写一条或多条 \*\*artifact（工件）\*\*。每条工件是一个三元组： - \*\*唯一标识符（identifier）\*\*：如 \`a017\`； - \*\*触发条件（trigger）\*\*：描述该工件适用于何种结构化的任务情境； - \*\*自由文本内容（content）\*\*：可包含程序性指导、检查清单、通用模式或注意事项。 所有工件必须满足\*\*领域通用性\*\*约束：禁止包含特定实体名、数值、固定解题序列或训练实例的专属信息，确保其能迁移到同领域的未知实例。 #### 2.2 错误反思（Reflection） 若教师对某训练实例的初始答案不正确，则启动一次反思调用： - 向教师展示该实例的参考答案（ground truth）； - 要求教师复盘错误根源，并\*\*重新撰写\*\*新的工件； - 新工件将\*\*替换\*\*该实例首次尝试产生的工件（因首次工件基于有缺陷的推理，不可复用）。 --- ### 3. 工件库的清理（Bank Cleaning） 构建完成的原始库会经过一次由 LLM judge（由 T 兼任）执行的审计清理。Judge \*\*一次性读取全库\*\*，通过横向比较决定每条工件的去留： | 清理规则 | 判定标准 | |---------|---------| | \*\*实例泄露（Leakage）\*\* | 包含特定实体、情节、数值或固定解题序列 | | \*\*重复（Duplicate）\*\* | 与库中另一工件在触发条件与核心教训上重叠，仅保留表述最清晰完整的一条 | | \*\*琐碎（Trivial）\*\* | 仅为通用解题常识，不含非显然信息 | | \*\*不可行（Not Actionable）\*\* | 触发器过于模糊，或内容未指明学生应采取何种不同操作 | 经清理后保留的工件构成最终\*\*工件库（artifact bank）\*\*。 --- ### 4. 学生的两阶段推理（无梯度更新） 学生模型 S 的权重保持冻结，在推理时通过以下两阶段调用工件库： #### 4.1 选择阶段（Selection） - \*\*输入\*\*：待求解任务，以及一份\*\*清单（manifest）\*\*——仅包含每条工件的标识符与触发条件，\*\*不暴露其完整内容\*\*； - \*\*操作\*\*： S 判断哪些工件的触发条件与当前任务的结构匹配，返回最精简的工件 ID 列表，或返回 \`NONE\`； - \*\*约束\*\*：要求基于任务\*\*结构类型\*\*而非具体数值进行匹配，禁止在选择阶段直接解题。 #### 4.2 回答阶段（Answer） - \*\*输入\*\*：待求解任务，以及在选择阶段被选中的工件的\*\*完整内容\*\*； - \*\*操作\*\*： S 在全新调用中结合这些策略性指导生成最终答案。 此设计的目的是避免学生被大量文本淹没，同时确保其仅在确认相关后才读取具体策略。 --- ### 5. 核心机制总结 | 机制 | 说明 | |-----|------| | \*\*知识外化\*\* | 教师能力以自然语言形式存入工件库，而非编码为学生权重 | | \*\*零梯度更新\*\* | 学生模型无需任何微调或 SFT，推理成本仅增加两次 API 调用（选择 + 回答） | | \*\*触发-内容分离\*\* | 学生先基于摘要式触发器做相关性判断，再读取详细内容，降低噪声干扰 | | \*\*可审计与复用\*\* | 工件为显式文本，可被人工检查、编辑，并可跨模型家族共享（如 Claude 教师 → Qwen 学生） | 通过上述流程，Artifact Distillation 将传统“参数化蒸馏”转变为“推理时检索式蒸馏”，在保留小模型轻量优势的同时，按需注入前沿模型的程序性知识。 Q4: 论文做了哪些实验？ 论文围绕 \*\*Artifact Distillation\*\* 的有效性、适用条件与工程细节开展了一系列实验，涵盖任务筛选、跨模型评估、机制消融与成本分析。具体实验内容如下： --- ### 1. 实验任务与数据划分 从 LiveBench（截至 2026 年 8 月未退役实例）的四个类别中，依据教师（Claude Opus 4.5）与学生（Claude Haiku 4.5）的\*\*无辅助准确率差距\*\* g = Acc_(Opus) - 原始库对较强学生增益有限（Pooled 分别仅 +0.020 与 +0.026 ），表明该方法对\*\*原本能力已较强\*\*的模型边际递减。 #### 3.2 清理库（Clean Bank）的对比实验 使用 Opus 4.5 作为 Judge，一次性审阅全库，按“泄露/重复/琐碎/不可行”四标准剔除不合格工件（243 条中删除 74 条，其中 58 条为重复）： - \*\*Haiku 4.5\*\*：Pooled 增益从 +0.071 降至 +0.039 ，主要损失来自 tablejoin（ -0.060 ）与 spatial（ -0.067 ）。 - \*\*spatial（成功）\*\*：工件要求“逐区域追踪边界并计数顶点”，使 Haiku 4.5 采用该策略的比例从 23% 升至 46%，直接弥合了 52% 的准确率差距。 - \*\*tablejoin（成功）\*\*：工件指导学生比较值分布而非列名，使 Haiku 4.5 平均返回列映射数从 2.2 提升至 3.2（接近 gold 的 3.2），Recall 从 0.47 提升至 0.70。 - \*\*connections（失败）\*\*：工件虽通用，但 87% 的无辅助答案已包含“检测隐藏公共词”步骤，缺乏 novelty；提升次要含义检查比例（6%→21%）未转化为准确率收益。 - \*\*math\_comp（失败）\*\*：工件提供的新技术过于狭窄，75% 的评估运行中 selector 返回 \`NONE\`，因很少有评估题需要这些特定技巧。 #### 4.2 清理造成的具体行为变化 - \*\*tablejoin\*\*：清理删除了 Haiku 4.5 最常选择的 4 条工件中的 3 条（ deemed 为重复），导致“按值匹配”建议从每实例 3.9 次降至 0.9 次；学生转而选择相互矛盾的策略，Precision 从 0.68 降至 0.62。 - \*\*spatial\*\*：被删除的重复工件中 38% 包含具体示例，而保留的仅 16% 包含示例。具体示例虽增加长度，但似乎是弱学生执行程序的关键，这解释了 Haiku 与 Opus 在清理后 spatial 上的（非显著）下滑。 --- ### 5. 附录中的补充实验与统计 - \*\*跨基准验证\*\*：当前四项任务均来自 LiveBench，在其他基准（如 SWE-bench、AgentBench 等）以及真实生产负载上的转移行为尚不明确。 - \*\*长程与智能体任务（Agentic Tasks）\*\*：论文仅考察单轮任务。在多步交互、工具调用或长程规划场景中，按需查询工件库的潜在价值可能更大，需验证工件库能否支撑动态决策与错误恢复。 ### 2. 跨模型家族的系统性转移规律 - 6. Supervised Fine-Tuning for Reasoning Large Language Models: A Survey

Abstract:Large reasoning models have recently demonstrated remarkable capabilities in solving complex tasks, where supervised fine-tuning (SFT) on long chain-of-thought data serves as a crucial foundation for eliciting and enhancing their reasoning abilities. Despite rapid progress in both improving and analyzing reasoning-oriented SFT, the field still lacks a systematic survey that consolidates its fast-growing literature. To fill this gap, we present a comprehensive review of recent advancements in reasoning SFT, examining the literature through the dual lenses of methodological design and analytical investigation. First, we review methodological improvements across the SFT pipeline and categorize them into data-centric approaches and algorithm-centric innovations. Second, we reorganize analytical studies along three dimensions: data characteristics, optimization dynamics, and mechanistic insights. Finally, by synthesizing current research focuses and remaining bottlenecks, we outline promising future directions for reasoning SFT. We hope this survey deepens the understanding of reasoning SFT and paves the way for advanced reasoning models.

Abstract:Listwise preference feedback offers richer supervision for large language model (LLMs) alignment than pairwise comparisons, but a full ranking also reveals more sensitive user preferences. Existing privacy-preserving alignment methods focus mainly on pairwise feedback, while listwise alignment under local differential privacy (LDP) remains unexplored. Extending LDP to this listwise domain raises a critical challenge: the high sensitivity of the full ranking space demands excessive noise, neutralizing the benefits of listwise supervision. To address this challenge, we analyze the interaction between supervision granularity and privacy noise in downstream training, and introduce a rank-aware exponential mechanism that privatizes listwise preference data into a low-sensitivity granularity suitable for downstream alignment. The mechanism leverages ranking information to sample a fixed-size binary partition, concentrating the noise near borderline items instead of perturbing all items uniformly as randomized response (RR) does. Empirical evaluations on downstream LLM alignment tasks show that our mechanism consistently outperforms existing LDP baselines at matched privacy budgets. The code is available at this https URL.

6. Intersectional Invariant Learning for Fair Deepfake Detection

Abstract:Deepfake detection models achieve high overall accuracy but exhibit large performance disparities across demographic groups, causing some groups to experience substantially higher false-positive rates than others. Existing fairness-aware methods address this by constraining model outputs to equalize group predictions, but do not tackle the underlying feature-level bias. As a result, models may still rely on demographic characteristics, such as skin texture, as indirect cues for detecting manipulated content. To address this problem, we propose Intersectional Invariant Learning (IIL), a framework that improves feature learning rather than only adjusting model outputs. IIL alternates between identifying the most challenging demographic partitions and learning features that remain consistent across those partitions. The framework also includes a false-positive-rate fairness objective and group-balanced sampling across six gender x skin-tone intersectional groups. We evaluate IIL on a large-scale fairness benchmark containing over one million images, 10 baseline detectors, and 21 fairness and utility metrics. Results show that IIL achieves Pareto-optimal performance, simultaneously attaining an AUC above 99%, a false-positive rate under 2.5%, and the lowest intersectional fairness disparity (FMEO) among all compared methods. IIL outperforms prior fairness-aware methods on the large majority of the 21 evaluation metrics, while reducing both false-positive rates and intersectional fairness disparities by several-fold compared with the strongest competing method.

7. FYC: FPR-Disparity Weight Perturbation and Youden Calibration for Fair Deepfake Detection

Abstract:Deepfake detectors routinely achieve high aggregate accuracy while exhibiting substantial demographic disparities in their errors: false-positive rates differ by double digits across gender and skin tone. Most existing remedies require either full retraining with a fairness-aware objective or demographic-annotated training data, both impractical when only a pretrained checkpoint is available, while label-free post-hoc calibrators leave the detector’s weights unchanged. We introduce FYC (FPR-disparity Weight Perturbation and Youden Calibration), a two-stage post-hoc method that perturbs a detector’s weights under an FPR-disparity criterion, then calibrates a separate decision threshold for each demographic group - requiring no architectural changes and no full retraining. Conditioning the same objective on real images only - our FPR-disparity criterion - eliminates this unpredictability, improving fairness and accuracy jointly across all four architectures with no exceptions.

9. You Don’t Need Aligned Representations: Knowledge Distillation via Random Prototype Spaces

Abstract:A widely held assumption in knowledge distillation is that teacher and student representations must occupy a compatible or explicitly aligned feature space. We propose RPKD (Random Prototype Knowledge Distillation), which discards this assumption by comparing both networks against a shared bank of randomly initialized, frozen prototype vectors. Alignment is therefore carried out in an external reference space rather than in the teacher’s native feature coordinates: the teacher side is projected by fixed random maps that carry no trainable parameters, and only the student adapts. Two branches handle the transfer: a logit branch aligning global prototype similarity distributions and a feature branch matching spatially-resolved prototype activation maps. Both operate within the same fixed prototype space, which can be interpreted as a random feature embedding that approximately preserves inter-sample similarity structure, so the prototype bank and the distillation objective stay unchanged across teacher-student pairs while only the input projections are instantiated per architecture. In low-category settings, decoupling the prototype vocabulary from the task label space yields richer supervision than the label space alone, an advantage absent from logit-based methods, whose supervisory signal collapses as class count shrinks. This advantage is especially relevant in real-world scenarios where the label space is typically constrained. Extensive experiments demonstrate the effectiveness of RPKD, achieving a maximum gain of +7.98% over OFA on CIFAR-100, +12.44% on ImageNet-100, and +1.28% on ImageNet-1K.
